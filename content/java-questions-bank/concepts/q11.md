## Questions with Answers

## Beginner (Fundamentals)

### 1. What is the use of the `main` method in Java?
**Answer**: It is the **entry point** of a Java program. JVM starts executing code from the `main` method.

### 2. Difference between a class and an object?
**Answer**: A **Class** is a blueprint/template; an **Object** is a real-world instance of that class.

### 3. What is the `Scanner` class?
**Answer**: A built-in utility class used to **read input** from the user (via keyboard).

### 4. Difference between `.java` and `.class` files?
**Answer**: `.java` contains human-readable source code; `.class` contains JVM-executable bytecode.

### 5. Difference between a class and a method?
**Answer**: A **Class** is a container for data and behavior; a **Method** is a specific block of code that performs an action.

### 6. What is a Wrapper class?
**Answer**: A class that wraps a primitive type (like `int`) into an object (like `Integer`). Required for Collections.

### 7. What is the `new` keyword?
**Answer**: Used to **instantiate** an object and allocate memory on the heap.

### 8. What are the main differences between C, C++, and Java?
**Answer**: Java is platform-independent (bytecode), fully object-oriented, and has automatic garbage collection (no pointers).

### 9. What is a constructor and why is it used?
**Answer**: A special method called when an object is created to **initialize its state**.

### 10. What is an Interface?
**Answer**: A contract that defines **what** a class should do, without defining **how**.

### 11. Access modifiers and their scopes?
**Answer**:
- **Public**: Anywhere.
- **Private**: Within class.
- **Protected**: Package + Subclasses.
- **Default**: Package only.

### 12. Difference between `while` and `do-while` loops?
**Answer**: `while` checks condition first; `do-while` executes once then checks.

### 13. Primitives vs. Non-Primitive data types?
**Answer**: Primitives store simple values; Non-Primitives store object references.

## Intermediate (Differences & Practical Logic)

### 1. Explain the OOPS concepts?
**Answer**: Inheritance (reuse), Polymorphism (many forms), Encapsulation (hiding), Abstraction (simplifying).

### 2. Difference between an Abstract Class and an Interface?
**Answer**: Abstract classes can have implemented methods and state; Interfaces are purely contracts (mostly abstract).

### 3. Difference between Abstraction and Encapsulation?
**Answer**: Abstraction hides complexity; Encapsulation hides data (using `private`).

### 4. `this` vs. `super` keyword?
**Answer**: `this` refers to current class; `super` refers to immediate parent class.

### 5. Difference between `final`, `finally`, and `finalize`?
**Answer**: `final` (constant), `finally` (cleanup block), `finalize` (GC method).

### 6. Difference between `default` and `protected`?
**Answer**: `default` is package-only; `protected` is package + child classes.

### 7. Why is String immutable in Java?
**Answer**: For security, performance (String Pool), and thread-safety.

### 8. Difference between `StringBuffer` and `StringBuilder`?
**Answer**: `StringBuffer` is synchronized (safe, slow); `StringBuilder` is not (fast).

### 9. Difference between `String s = "abc"` and `String s = new String("abc")`?
**Answer**: First uses String Pool; second creates a new object on heap.

### 10. Difference between `Array` and `ArrayList`?
**Answer**: Array is fixed-size; ArrayList is dynamic.

### 11. Difference between `List` and `Set`?
**Answer**: List allows duplicates and keeps order; Set prohibits duplicates.

### 12. Difference between `List` and `Map`?
**Answer**: List is a sequence of values; Map is a collection of key-value pairs.

### 13. Difference between `HashMap` and `HashTable?`?
**Answer**: `HashMap` is faster and allows nulls; `HashTable` is synchronized and disallows nulls.

### 14. What is Inheritance? Can we use inheritance in an Interface?
**Answer**: Class reuse. Yes, interfaces can extend other interfaces.

### 15. Explain Exception handling in Java?
**Answer**: Managing errors using `try-catch` blocks to keep the program running.

### 16. Difference between checked and unchecked exceptions?
**Answer**: Checked (compile-time, forced); Unchecked (runtime, usually logic errors).

## Advanced (Internal Mechanics & Complex Scenarios)

### 1. What is the Object class? Name some of its methods?
**Answer**: The root of all classes. Methods: `toString()`, `equals()`, `hashCode()`.

### 2. What is polymorphism? Explain Static and Dynamic polymorphism?
**Answer**: **Static** (Overloading, compile-time); **Dynamic** (Overriding, run-time).

### 3. Can you execute a method without a `main` method?
**Answer**: Yes, using a static block or a test framework like TestNG.

### 4. What is a Copy Constructor?
**Answer**: Initializes a new object using an existing object of the same class.

### 5. What is Constructor Chaining?
**Answer**: Calling one constructor from another (using `this()` or `super()`).

### 6. Can we use static methods in a constructor?
**Answer**: Yes, but they don't help initialize the object instance.

### 7. Dependency Injection via Constructor?
**Answer**: Passing required objects (like `WebDriver`) into a class through its constructor.

### 8. What happens if an interface is implemented but a method is not given a body?
**Answer**: The implementing class must be declared `abstract`.

### 9. Can we write non-abstract methods in an Interface?
**Answer**: Yes, using `default` or `static` keywords since Java 8.

### 10. Can we create a constructor for an Abstract Class?
**Answer**: Yes, it is called when a child class object is created.

### 11. Can we create an object of a fully abstract class?
**Answer**: No, abstract classes cannot be instantiated.

### 12. What is Multiple Inheritance and why is it handled via Interfaces in Java?
**Answer**: Inheriting from two parents. Java uses Interfaces to avoid the "Diamond Problem."

### 13. How do you implement Hybrid Inheritance?
**Answer**: By using a combination of multiple types of inheritance (via Interfaces).

### 14. Explain Multilevel Inheritance?
**Answer**: A chain of inheritance (A -> B -> C).

### 15. What happens if the `static` keyword is missing from the `main` method?
**Answer**: The JVM won't recognize it as the entry point.

### 16. How does a `HashMap` work internally?
**Answer**: Uses hashing to store key-value pairs in buckets. Uses `hashCode()` and `equals()`.

### 17. How do you convert a `HashMap` to an Array?
**Answer**: `map.values().toArray()` or `map.keySet().toArray()`.

### 18. What is Serialization in Java?
**Answer**: Converting an object to a byte stream for storage or transfer.
