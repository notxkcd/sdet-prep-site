## Questions with Answers

## Beginner (Fundamentals)

### 1. What is OOPS?
**Answer**: Object-Oriented Programming (OOPS) is a programming paradigm based on "objects" that represent real-world entities, focusing on data and its interactions to make code modular and reusable.

### 2. What is the difference between a Class and an Object?
**Answer**: A **Class** is a blueprint or template (e.g., a "Car" design); an **Object** is a physical instance of that blueprint (e.g., your actual "Red Tesla").

### 3. Explain the "four pillars" of OOPS?
**Answer**:
- **Encapsulation**: Hiding data using `private` access and `public` methods.
- **Inheritance**: Code reuse via `extends`.
- **Polymorphism**: One method name, multiple behaviors.
- **Abstraction**: Hiding complexity via interfaces or abstract classes.

### 4. What is the syntax for declaring, initializing, and accessing arrays in Java?
**Answer**:
- **Declare**: `int[] arr;`
- **Init**: `arr = new int[5];`
- **Access**: `int x = arr[0];`

### 5. What is the difference between an Abstract Class and an Interface?
**Answer**: Abstract classes can have implemented methods and state (instance variables); Interfaces are purely contracts defining behavior (mostly abstract methods).

## Intermediate (Practical Concepts & Implementation)

### 1. Explain the key principles of OOPS?
**Answer**: Modularity (small units), Reusability (reusing code), Scalability (expanding system), Real-World Modeling (objects), and Security (data hiding).

### 2. How is OOPS implemented in Java specifically?
**Answer**: Using `class` and `interface` keywords, `access modifiers`, and built-in keywords like `extends`, `implements`, `super`, and `this`.

### 3. What are the types of Inheritance supported in Java?
**Answer**: **Single** (A->B), **Multilevel** (A->B->C), and **Hierarchical** (A->B, A->C). Multiple inheritance is supported only via Interfaces.

### 4. Explain the difference between Overloading and Overriding?
**Answer**: **Overloading** is same class, diff parameters (compile-time); **Overriding** is parent/child, same parameters (run-time).

### 5. What is the difference between a String Literal and a Non-Literal String?
**Answer**: **Literal** (`"abc"`) uses the String Pool; **Non-Literal** (`new String("abc")`) creates a new object on the heap.

### 6. Explain why Strings are immutable and how it relates to encapsulation?
**Answer**: Immutability means the state cannot change, protecting the data from accidental modification (encapsulation) and allowing safe sharing in memory.

## Advanced (Internal Mechanics & Scenarios)

### 1. Explain the difference between Association, Aggregation, and Composition?
**Answer**: **Association** is any relationship; **Aggregation** is a weak "has-a" (part lives without whole); **Composition** is a strong "has-a" (part dies with whole).

### 2. What is Type Casting?
**Answer**: **Upcasting** is subclass to superclass (automatic/safe); **Downcasting** is superclass to subclass (manual/needs `instanceof`).

### 3. How are OOPS concepts applied in a Selenium automation framework?
**Answer**: **Encapsulation** in POM classes; **Inheritance** in Base setup classes; **Polymorphism** in WebDriver setup; **Abstraction** in element interaction interfaces.

### 4. How does the String Pool work in Java?
**Answer**: It is a cache of string objects. When a literal is created, the JVM checks the pool first to reuse an existing reference, saving memory.

### 5. How can arrays be used to demonstrate polymorphism?
**Answer**: An array of a superclass type can hold objects of any of its subclasses (e.g., `Animal[] arr = {new Dog(), new Cat()};`).
