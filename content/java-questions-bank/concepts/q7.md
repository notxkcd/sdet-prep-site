## Questions with Answers

## Beginner (Fundamentals)

### 1. What is abstraction?
**Answer**: Abstraction is the process of hiding internal implementation details and showing only the essential functionality to the user (the "what," not the "how").

### 2. What is the `static` keyword?
**Answer**: It means the variable or method belongs to the **class** itself rather than any specific instance. It is shared by all objects of that class.

### 3. What is the use of the `super` keyword?
**Answer**: To refer to the immediate parent class instance, call parent constructors (`super()`), or access parent methods.

### 4. Explain the `this` keyword?
**Answer**: Refers to the **current class instance**. It's commonly used to resolve naming conflicts between instance variables and method parameters.

### 5. Member access modifiers (Public, Private, Protected, Default)?
**Answer**:
- **public**: Accessible everywhere.
- **private**: Accessible only within the class.
- **protected**: Accessible in the same package and by subclasses.
- **default**: Accessible only within the same package.

### 6. What is a `HashMap`?
**Answer**: A collection that stores data in **Key-Value pairs**. It uses hashing for fast retrieval and allows one null key.

### 7. What is a `NullPointerException` and how do you avoid it?
**Answer**: Occurs when trying to access a member of a `null` object. Avoid it by using null checks (`if (obj != null)`) or the `Optional` class.

## Intermediate (Implementation & Logical Differences)

### 1. Difference between `final` and `finally`?
**Answer**: `final` is a keyword for restrictions (constants, no overriding); `finally` is a block that always executes after try-catch for cleanup.

### 2. Explain `static` and `final` keywords?
**Answer**: `static` means shared by class; `final` means unchangeable value/behavior.

### 3. Difference between an `Abstract Class` and an `Interface`?
**Answer**: Abstract classes can have implemented methods and state; Interfaces are behavior contracts (purely abstract before Java 8).

### 4. Why use an Interface instead of an Abstract Class?
**Answer**: To support multiple inheritance of behavior and to provide a common contract for unrelated classes.

### 5. Inheritance: How is it used in your project?
**Answer**: To inherit common setup/teardown logic and utility methods from a `BasePage` or `BaseTest` class.

### 6. Where have you applied overloading and overriding methods in your project?
**Answer**: Overloading for generic element actions (diff params); Overriding for page-specific implementation of base methods.

### 7. Difference between `List` and `Set`?
**Answer**: **List** is ordered and allows duplicates; **Set** is unordered and prohibits duplicates.

### 8. Difference between `Array` and `ArrayList`?
**Answer**: **Array** is fixed-size; **ArrayList** is dynamic and part of the Collections framework.

### 9. Can we use multiple `catch` blocks in Java?
**Answer**: Yes, to handle different types of exceptions separately within a single try-catch structure.

### 10. Difference between `throw` and `throws`?
**Answer**: `throw` is used to trigger an exception; `throws` is used in the method signature to declare potential exceptions.

### 11. How do you handle exceptions like `ArithmeticException`?
**Answer**: By wrapping the calculation in a `try-catch` block to gracefully handle errors like division by zero.

### 12. How to sort a collection using `Collections.sort()`?
**Answer**: `Collections.sort(list);` sorts the given List based on natural ordering or a custom `Comparator`.

## Advanced (Deep Dives & Scenarios)

### 1. What are the OOPS concepts in Java and how are they implemented in your Selenium project?
**Answer**: Encapsulation (POM classes), Inheritance (Base classes), Polymorphism (WebDriver interface), Abstraction (WebElement actions).

### 2. How can you access all methods of Class A in Class B?
**Answer**: Through **Inheritance** (`B extends A`) or **Composition** (B has an instance of A).

### 3. How do you use constructors in Selenium/Java?
**Answer**: To initialize the `WebDriver` object and set up page factory elements when a page object is created.

### 4. What is a functional interface?
**Answer**: An interface with **exactly one abstract method** (e.g., `Predicate`, `Consumer`).

### 5. What is a lambda expression?
**Answer**: A concise way to represent a functional interface implementation as an anonymous function.

### 6. Where have you used the Collections framework in your automation project?
**Answer**: `List<WebElement>` for finding multiple elements; `Map<String, String>` for storing test data or configuration.

### 7. Explain the Java Collections framework and the data structures it provides?
**Answer**: A unified architecture providing interfaces (`List`, `Set`, `Map`) and classes (`ArrayList`, `HashSet`, `HashMap`) to manage groups of objects.

### 8. If you use 3 `catch` blocks, how will you declare their hierarchy?
**Answer**: Most specific exceptions (subclasses) must come first, followed by more general ones (superclasses).

### 9. Apart from `try-catch`, how can you handle exceptions in Java?
**Answer**: Using the `throws` keyword to propagate the exception up the call stack.

### 10. Difference between `Thread.sleep()` and `Thread.wait()`?
**Answer**: `sleep()` is a timed pause that keeps locks; `wait()` is for synchronization and releases the lock until notified.
