## Questions with Answers

## Beginner (Basics)

### 1. What is the use of `pom.xml` in your project?
**Answer**: It is the **Project Object Model** file for Maven. It manages all project configurations, including dependencies, plugins, and project version.

### 2. What are the dependencies used in your project?
**Answer**: Common ones include `selenium-java`, `cucumber-java`, `cucumber-junit`, `testng`, and `apache-poi`.

## Intermediate (Configuration & Usage)

### 1. Other than dependencies, what else is present in the `pom.xml` file?
**Answer**: It contains `<build>` tags for **Plugins** (like Surefire), `<properties>` for custom variables (like Java version), and repository details.

### 2. What is the purpose of the Maven `Pretty` and `Plugin` configurations?
**Answer**: Plugins automate tasks like compilation or testing. `Pretty` usually refers to reporting plugins that format the output into readable HTML or JSON reports.

### 3. How do you handle test data and external data in your framework?
**Answer**: By using external files like **Excel** (via Apache POI), **JSON**, or **Properties** files, keeping the data completely separate from the code logic.

## Advanced (Framework Architecture & Logic)

### 1. What do you know about Page Factory and how do you use it in a Java/Cucumber framework?
**Answer**: It is a class in Selenium that implements the Page Object Model. It uses `@FindBy` to locate elements and `PageFactory.initElements()` to initialize them lazily.

### 2. Where do you store the expected output data in your framework for `Assert` validation?
**Answer**: Typically in **Excel files** or a separate **Constants class** within the framework to ensure validations are easy to maintain and update.
