## Questions with Answers

## Beginner (Basics & Definitions)

### 1. What are the data types in Java?
**Answer**:
- **Primitive**: `byte`, `short`, `int`, `long`, `float`, `double`, `boolean`, `char`.
- **Non-Primitive**: `String`, `Array`, `Class`, `Interface`.

### 2. Explain the `super` and `this` keywords?
**Answer**: `this` refers to the current class instance; `super` refers to the immediate parent class instance.

### 3. What is the `new` keyword in Java?
**Answer**: Used to create an instance of a class by allocating memory on the heap.

### 4. What is a Wrapper class?
**Answer**: Classes that convert primitive types into objects (e.g., `Integer` for `int`).

### 5. What are the different types of access modifiers?
**Answer**: `public` (anywhere), `private` (class-only), `protected` (package+subclass), `default` (package-only).

### 6. What is the purpose of the `static` keyword in the `main` method?
**Answer**: It allows the JVM to execute the `main` method without having to instantiate the class first.

### 7. What is the `java.awt` package?
**Answer**: Abstract Window Toolkit; used for creating GUI components like buttons and windows.

### 8. What are the uses of the JDK?
**Answer**: The Java Development Kit provides tools (like `javac` and `jdb`) to compile, debug, and run Java applications.

### 9. Difference between a `.java` file and a `.class` file?
**Answer**: `.java` is the source code file; `.class` is the compiled bytecode file executed by the JVM.

### 10. Difference between `while` and `do-while` loops?
**Answer**: `while` checks the condition before execution; `do-while` executes once and then checks the condition.

### 11. What is a `NullPointerException`?
**Answer**: Thrown when an application attempts to use `null` where an object instance is required.

### 12. What is an `ArithmeticException`?
**Answer**: Thrown when an exceptional arithmetic condition has occurred (e.g., divide by zero).

## Intermediate (Differences & Practical Logic)

### 1. Difference between `this` and `super`?
**Answer**: `this()` calls a constructor in the same class; `super()` calls a constructor in the parent class.

### 2. Difference between Abstraction and Encapsulation?
**Answer**: Abstraction hides implementation complexity; Encapsulation hides data and restricts access via `private`.

### 3. Difference between an Abstract Class and an Interface?
**Answer**: Abstract class can have state and shared code; Interface is a contract defining behavior (mostly abstract).

### 4. Difference between a Method and a Constructor?
**Answer**: A method performs an operation and has a return type; a constructor initializes an object and has no return type.

### 5. What is a Constructor?
**Answer**: A special block of code used to initialize a new object.

### 6. Difference between `final`, `finally`, and `finalize`?
**Answer**: `final` (restriction), `finally` (cleanup block), `finalize` (GC cleanup method).

### 7. Difference between `StringBuffer` and `StringBuilder`?
**Answer**: `StringBuffer` is synchronized (thread-safe); `StringBuilder` is not (faster).

### 8. Difference between `String str = "abc"` and `String str = new String("abc")`?
**Answer**: First one uses the String Pool; second one creates a new object on the heap.

### 9. What is the difference between `List` and `Map`?
**Answer**: **List** is a sequence of elements; **Map** is a collection of key-value pairs.

### 10. What is `Set`?
**Answer**: A collection that contains no duplicate elements.

### 11. Difference between `ArrayList` and `LinkedList`?
**Answer**: `ArrayList` uses a dynamic array (better retrieval); `LinkedList` uses nodes (better modification).

### 12. Difference between `HashMap` and `HashTable`?
**Answer**: `HashMap` is non-synchronized and allows nulls; `HashTable` is synchronized and disallows nulls.

### 13. What are checked and unchecked exceptions?
**Answer**: **Checked** are caught at compile-time (IOException); **Unchecked** are caught at runtime (NullPointerException).

### 14. Scope and differences between `default`, `protected`, and `private`?
**Answer**: `private` (class), `default` (package), `protected` (package + subclasses).

### 15. What is the scope of a private method?
**Answer**: Only visible and accessible within the class where it is defined.

### 16. How do you find the square root of a number in Java using a direct method?
**Answer**: Using `Math.sqrt(number);`.

## Advanced (Internal Workings & Project Integration)

### 1. What are the OOPS concepts and how are they used in your project?
**Answer**: Used to structure the framework: Inheritance for Base classes, Encapsulation for POM, and Abstraction for WebDriver.

### 2. What are Copy Constructors and Constructor Chaining?
**Answer**: **Copy Constructor** initializes an object using another object of the same class. **Chaining** is calling constructors sequentially using `this()` or `super()`.

### 3. What is the return type of a constructor?
**Answer**: It has no return type (not even `void`).

### 4. Can we use static methods in a constructor?
**Answer**: Yes, but it is uncommon as constructors are meant for instance initialization.

### 5. What is a Static block in Java?
**Answer**: A block of code that runs once when the class is first loaded into memory.

### 6. Can we override static methods?
**Answer**: No, static methods are hidden (Method Hiding) rather than overridden.

### 7. What happens if the `static` keyword is missing from `main`?
**Answer**: The JVM will not be able to find the entry point and the program won't run.

### 8. Can the order of `public static void` be changed in the `main` method?
**Answer**: `public` and `static` can be swapped, but `void` must stay before `main`.

### 9. Can we write a `try-catch` block without the `catch` block?
**Answer**: Yes, provided it is followed by a `finally` block.

### 10. What is a functional interface?
**Answer**: An interface with exactly one abstract method (e.g., `Runnable`).

### 11. Difference between static and abstract classes?
**Answer**: Abstract classes cannot be instantiated; Static classes (nested) can be accessed without a parent instance.

### 12. How do you use Collections in your framework?
**Answer**: `List<WebElement>` for multiple elements and `Map` for storing test data.
