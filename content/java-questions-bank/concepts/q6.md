## Questions with Answers

## Beginner (Basic Syntax & OOPS Basics)

### 1. What is an abstract class? Provide an example?
**Answer**: A class that cannot be instantiated and is used as a base for other classes. Example: `abstract class Animal { abstract void makeSound(); }`.

### 2. What is Abstraction and where is it used?
**Answer**: Hiding complex implementation and showing only functionality. Used in Java through Interfaces and Abstract classes.

### 3. Explain Polymorphism?
**Answer**: "One name, many forms." It allows objects to behave differently based on their implementation (Overloading and Overriding).

### 4. What are Wrapper classes?
**Answer**: Classes like `Integer` and `Double` that allow primitive data types to be treated as objects.

### 5. What is the purpose of the `super` keyword?
**Answer**: To refer to the immediate parent class instance, call parent constructors, or access parent methods.

### 6. What are the access modifiers and their differences?
**Answer**:
- **public**: Accessible everywhere.
- **private**: Accessible only within the class.
- **protected**: Accessible in the package and by subclasses.
- **default**: Accessible only within the same package.

### 7. What is an exception in Java? How do you handle it?
**Answer**: An event that disrupts normal execution. Handled using `try-catch` blocks to prevent the program from crashing.

### 8. Difference between `for` loop and enhanced `for` loop?
**Answer**: Standard `for` uses an index; enhanced `for` (for-each) directly iterates through elements of an array or collection.

### 9. What are the ways to convert a String to an Integer?
**Answer**: `Integer.parseInt(str)` (returns int) or `Integer.valueOf(str)` (returns Integer object).

## Intermediate (Practical Implementation & Differences)

### 1. Inheritance: How is it used in your project?
**Answer**: To reuse common automation logic (like browser setup) by having specific test classes extend a `BaseTest` class.

### 2. Where have you implemented Encapsulation in your Automation Framework?
**Answer**: In Page Object Model (POM), by making locators `private` and exposing them through `public` interaction methods.

### 3. Constructor types and explanations?
**Answer**:
- **Default**: Provided by Java if none is written.
- **Parameterized**: User-defined to initialize objects with specific values.

### 4. What is `final`, `finally`, and `finalize`?
**Answer**: `final` (constant), `finally` (cleanup block), `finalize` (GC cleanup method).

### 5. Difference between static and instance variables?
**Answer**: `static` belongs to the class (shared); `instance` belongs to the object (unique).

### 6. Explain the difference between `==` and `.equals()`?
**Answer**: `==` compares references (memory location); `.equals()` compares content (values).

### 7. What is the difference between `StringBuffer` and `StringBuilder`?
**Answer**: `StringBuffer` is synchronized (thread-safe); `StringBuilder` is faster but not thread-safe.

### 8. Difference between `Collection` and `Collections`?
**Answer**: `Collection` is an interface; `Collections` is a utility class with static methods for manipulation.

### 9. Explain the Collection framework briefly?
**Answer**: A unified architecture providing interfaces and classes to store and process a group of objects efficiently.

### 10. Difference between `Array` and `ArrayList`?
**Answer**: Array is fixed-size; ArrayList is dynamic-sized.

### 11. Difference between `List` and `Set`?
**Answer**: List is ordered and allows duplicates; Set is unordered and prohibits duplicates.

### 12. Difference between `Map` and `List`?
**Answer**: List is a sequence of objects; Map is a collection of key-value pairs.

### 13. Difference between `Map` and `Set`?
**Answer**: Set contains only unique values; Map contains unique keys mapped to values.

### 14. Difference between `throw` and `throws`?
**Answer**: `throw` triggers an exception; `throws` declares that a method might throw an exception.

### 15. Difference between `Exception`, `Error`, and `Assertion`?
**Answer**: Exception is recoverable; Error is a serious system failure; Assertion is used for verifying assumptions.

### 16. What is a `NullPointerException`?
**Answer**: Occurs when trying to access methods or fields of an object reference that is `null`.

### 17. How do you iterate through a `HashMap`?
**Answer**: Using `entrySet()` with a for-each loop to access both keys and values.

### 18. How many `catch` blocks can be used for a single `try`?
**Answer**: Multiple, but only the first matching catch block will execute.

## Advanced (Internal Mechanics, Design & Framework Architecture)

### 1. What design patterns have you used in your Automation Framework?
**Answer**: Page Object Model (POM), Singleton (for Driver), and Factory Pattern.

### 2. What is the Singleton Design Pattern?
**Answer**: Ensures a class has only one instance and provides a global access point to it.

### 3. Explain how we achieve 100% Abstraction in Java?
**Answer**: By using **Interfaces** (all methods are abstract by default).

### 4. If you have 10 methods in an Interface and you implement all except one, what will happen?
**Answer**: The class must be declared `abstract`, otherwise it will not compile.

### 5. What is meant by Serialization and Deserialization in Java?
**Answer**: Converting an object into a byte stream (Serialization) and converting it back into an object (Deserialization).

### 6. What is constructor chaining?
**Answer**: Calling one constructor from another within the same or parent class using `this()` or `super()`.

### 7. Difference between POM and Page Factory?
**Answer**: POM is a design pattern; Page Factory is a Selenium class that implements POM with lazy initialization via `@FindBy`.

### 8. Do we have many public classes inside a single Java file?
**Answer**: No, only one public class is allowed, and its name must match the filename.

### 9. Can we execute Java code without the `main()` method?
**Answer**: Yes, using a static block (prior to Java 7) or using testing frameworks like TestNG.

### 10. Will the `main` method run without the `static` keyword?
**Answer**: No, the JVM will not recognize it as the entry point.

### 11. Can a `finally` block execute without `try` and `catch` blocks?
**Answer**: No, it must be associated with a `try` block.

### 12. Explain Type Casting of objects in OOPS?
**Answer**: **Upcasting** (automatic, child to parent) and **Downcasting** (explicit, parent to child).

### 13. What is a functional interface?
**Answer**: An interface with exactly one abstract method (e.g., `Runnable`).

### 14. What is a lambda expression?
**Answer**: A concise way to represent an anonymous function for functional interfaces.

### 15. Exception in superclass vs subclass?
**Answer**: A subclass overriding a method cannot throw a broader checked exception than the parent method.

### 16. Are you aware of `HashMap` and `HashTable`?
**Answer**: `HashMap` is non-synchronized (faster) and allows one null key; `HashTable` is synchronized (slower) and allows no nulls.

### 17. How many `finally` blocks can be used with a `try` block?
**Answer**: Only one.
