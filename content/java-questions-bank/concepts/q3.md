## Questions with Answers

## Beginner (Basics)

### 1. What is a Variable?
**Answer**: A named container in memory used to store data values during program execution (e.g., `int age = 25;`).

### 2. Difference between Local and Global variables?
**Answer**:
- **Local**: Declared inside a method; destroyed when the method completes.
- **Global (Instance)**: Declared inside a class but outside methods; accessible by all methods in that class.

### 3. Explain Looping statements?
**Answer**: Used to execute a block of code repeatedly based on a condition. Common loops: `for`, `while`, `do-while`.

### 4. Explain Conditional statements?
**Answer**: Used to make decisions in code based on boolean logic (e.g., `if`, `else if`, `switch`).

### 5. What is the syntax for `if-else` conditions?
**Answer**:
```java
if (condition) {
    // executes if true
} else {
    // executes if false
}
```

### 6. What are the uses of a Constructor?
**Answer**: To initialize an object's initial state and allocate memory when it is created.

### 7. Difference between `==` and `.equals()`?
**Answer**: `==` checks if two references point to the same memory location; `.equals()` checks if the actual values (content) are the same.

## Intermediate (Conceptual Implementation)

### 1. What is the difference between an Abstract Class and an Interface?
**Answer**: Abstract Class can have state and implemented methods; Interfaces are pure contracts (only abstract methods before Java 8).

### 2. Why do we use an Interface?
**Answer**: To achieve 100% abstraction, define a contract for unrelated classes, and support multiple inheritance of behavior.

### 3. What is the difference between Method Overloading and Method Overriding?
**Answer**: **Overloading** is same class, diff parameters; **Overriding** is parent/child, same parameters.

### 4. What is a Constructor and how is it used in your framework?
**Answer**: Used to initialize the `WebDriver` instance or set up page objects when they are instantiated.

### 5. Explain Inheritance and how it is implemented in your project?
**Answer**: Mechanism to reuse code from a parent class. Implemented by having Page classes extend a `BasePage` class.

### 6. How can you call a static variable from another class?
**Answer**: Directly using the class name: `ClassName.variableName;`.

### 7. Difference between `StringBuffer` and `StringBuilder`?
**Answer**: `StringBuffer` is synchronized (thread-safe); `StringBuilder` is faster (not thread-safe).

### 8. Explain Collections concept in general?
**Answer**: A framework providing a set of interfaces and classes to store and manipulate groups of data efficiently (e.g., searching, sorting).

## Advanced (Internal & Project Specific)

### 1. Where do you use Overloading and Overriding in your automation framework?
**Answer**:
- **Overloading**: Generic click methods (e.g., `click(element)` vs `click(locator, timeout)`).
- **Overriding**: Custom methods in specific page classes that redefine behavior from the `BasePage`.

### 2. How can you access all methods of Class A in Class B?
**Answer**: By using **Inheritance** (`class B extends A`).

### 3. If you have multiple methods, how do you handle the return statements?
**Answer**: Each method must specify its return type (e.g., `int`, `String`, `void`) and use the `return` keyword to pass data back.

### 4. What is a Linked List and where have you used it in your project?
**Answer**: A dynamic data structure where elements point to each other. Used when frequent additions and deletions of data are required.

### 5. How do you throw a custom exception?
**Answer**:
```java
class MyException extends Exception {
    MyException(String msg) { super(msg); }
}
// Usage:
if (error) throw new MyException("Error occurred");
```
