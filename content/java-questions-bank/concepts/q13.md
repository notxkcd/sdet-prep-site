## Questions with Answers

## Beginner

### 1. What is TestNG and explain why and where it is required?
**Answer**: TestNG is a powerful testing framework inspired by JUnit. It is required for managing complex automation suites, providing advanced features like grouping, prioritization, and dependency management.

### 2. What are the advantages of TestNG?
**Answer**: It offers flexible test configurations, data-driven testing using `@DataProvider`, detailed reporting, and support for parallel execution.

### 3. List TestNG annotations and explain their execution order?
**Answer**:
1. `@BeforeSuite` -> 2. `@BeforeTest` -> 3. `@BeforeClass` -> 4. `@BeforeMethod` -> 5. **`@Test`** -> 6. `@AfterMethod` -> 7. `@AfterClass` -> 8. `@AfterTest` -> 9. `@AfterSuite`.

## Intermediate

### 1. What is the use of `testng.xml` and what is the sequence used in it?
**Answer**: It is used to define and execute test suites. The XML sequence is: `<suite>` -> `<test>` -> `<classes>` -> `<class>` -> `<methods>`.

### 2. What is a Data Provider in TestNG?
**Answer**: A specialized annotation (`@DataProvider`) that allows a test method to be executed multiple times with different sets of input data.

### 3. How do you rerun failed test cases in TestNG?
**Answer**: By running the `testng-failed.xml` file located in the `test-output` folder, or by implementing the `IRetryAnalyzer` interface for automatic retries.

### 4. How do you perform parameterization in TestNG?
**Answer**: Using the `@Parameters` annotation to read values from the `testng.xml` file or using the `@DataProvider` annotation for complex data sets.

### 5. How do you generate reports in TestNG?
**Answer**: TestNG automatically generates HTML and XML reports in the `test-output` folder. Custom reports can be created using `ITestListener` or `IReporter` interfaces.

### 6. How do you pass test data in TestNG?
**Answer**: Via the `testng.xml` parameters or by using `@DataProvider` methods which return a 2D array of objects.

### 7. How do you set priority in TestNG? What happens if no priority is set?
**Answer**: Use the `priority` attribute: `@Test(priority = 1)`. If not set, all tests default to priority 0 and run in alphabetical order.

### 8. How can you ignore or skip a particular test case in TestNG?
**Answer**: Use `@Test(enabled = false)` to ignore a test, or throw a `SkipException` during runtime to skip based on a condition.

### 9. How do you run a particular method multiple times in TestNG?
**Answer**: Use the `invocationCount` attribute: `@Test(invocationCount = 10)`.

### 10. Why choose TestNG over other frameworks like JUnit or Cucumber?
**Answer**: It provides more control over the execution flow (parallel, priority, groups) than JUnit and is less technically complex to set up than Cucumber.

## Advanced

### 1. How do you perform parallel execution in TestNG?
**Answer**: In the `testng.xml` file, set the `parallel` attribute in the `<suite>` tag (e.g., `parallel="methods"`) and specify the `thread-count`.

### 2. Explain the priority logic when some tests have priority and others do not?
**Answer**: Tests with negative priority run first, followed by those with priority 0 (default, run alphabetically), and then tests with positive priorities.
