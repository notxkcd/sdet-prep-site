## Questions with Answers

## Beginner (Basics)

### 1. Explain the OOPS concepts?
**Answer**:
- **Encapsulation**: Hiding data using `private` access.
- **Inheritance**: Code reuse via `extends`.
- **Polymorphism**: One method, multiple behaviors.
- **Abstraction**: Hiding complexity via interfaces/abstract classes.

### 2. What are the access specifiers in Java?
**Answer**:
- `public`: Accessible everywhere.
- `private`: Accessible only within the class.
- `protected`: Accessible within package and child classes.
- `default`: Accessible only within the same package.

### 3. Difference between JDK and JRE?
**Answer**: **JDK** (Java Development Kit) is used to create and compile code; **JRE** (Java Runtime Environment) is the environment used to run the compiled code.

### 4. How do you read input in Java?
**Answer**: Using the `Scanner` class:
```java
Scanner s = new Scanner(System.in);
String data = s.nextLine();
```

### 5. Is `TakesScreenshot` a class or an interface in Selenium?
**Answer**: It is an **Interface**.

## Intermediate (Differences & Practical Logic)

### 1. What are the differences between an Abstract Class and an Interface?
**Answer**: Abstract classes can have implemented methods and state (fields); Interfaces are contracts defining behavior (mostly abstract methods).

### 2. What is the difference between Method Overloading and Method Overriding?
**Answer**: **Overloading** happens in the same class (diff params); **Overriding** happens in parent/child classes (same params).

### 3. What is the difference between `final` and `finally`?
**Answer**: `final` is used to restrict (constant variables, non-overridable methods); `finally` is a block used for cleanup after try-catch.

### 4. What is the difference between a `List` and a `Set`?
**Answer**: **List** maintains insertion order and allows duplicates; **Set** is unordered and prohibits duplicates.

### 5. Explain the Java Collection framework?
**Answer**: A hierarchy of interfaces and classes (like `ArrayList`, `HashSet`, `HashMap`) used to manage and manipulate a group of objects.

### 6. Explain the `HashMap` in detail?
**Answer**: A data structure that stores key-value pairs. It uses hashing to achieve fast retrieval and allows one null key.

### 7. What is the difference between a `Collection` and a `Set`?
**Answer**: `Collection` is the root interface; `Set` is a specific sub-interface that enforces unique elements.

### 8. Is `JavaScript` a class or an interface?
**Answer**: In the context of Selenium, `JavascriptExecutor` is an **Interface**.

## Advanced (Internal Mechanics & Complex Scenarios)

### 1. Explain the difference between Static Binding and Dynamic Binding?
**Answer**: **Static Binding** (Early) is resolved at compile-time (e.g., static or private methods); **Dynamic Binding** (Late) is resolved at run-time (e.g., overridden methods).

### 2. What is Compile-time Polymorphism?
**Answer**: Another name for **Method Overloading**, where the method to call is determined by the compiler based on the parameters.

### 3. Can a static method be overridden?
**Answer**: **No**. If a child class has a static method with the same signature, it is called "Method Hiding."

### 4. What is synchronization in Java and how do you handle it?
**Answer**: It prevents multiple threads from accessing a resource simultaneously to avoid data inconsistency. Handled using the `synchronized` keyword.

### 5. Write the code for using `entrySet()` in a `Map`?
**Answer**:
```java
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " : " + entry.getValue());
}
```
