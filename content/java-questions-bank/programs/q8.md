## Questions with Answers

## Beginner (Basics)

### 1. Write a program to reverse a string (Generic)?
**Solution**:
```java
String s = "Java";
String rev = new StringBuilder(s).reverse().toString();
```

### 2. Reverse a string using a loop and using an inbuilt function?
**Solution**:
- **Loop**: `for(int i=s.length()-1; i>=0; i--) rev += s.charAt(i);`
- **Inbuilt**: `new StringBuilder(s).reverse().toString();`

### 3. Print the first 3 characters of a string?
**Solution**:
```java
System.out.println(s.substring(0, 3));
```

### 4. Find the minimum and maximum value in an array?
**Solution**:
```java
int min = arr[0], max = arr[0];
for(int x : arr) {
    if(x < min) min = x;
    if(x > max) max = x;
}
```

## Intermediate (Intermediate Logic)

### 1. Manipulate a string: write your name, print its length, add characters, and then print the name/length multiple times?
**Solution**:
```java
String name = "Shahid";
System.out.println(name.length());
name += " CLI";
for(int i=0; i<5; i++) System.out.println(name);
```

### 2. Input: `abc`, Output: `aabbcc`?
**Solution**:
```java
String s = "abc", res = "";
for(char c : s.toCharArray()) res = res + c + c;
```

## Advanced (Advanced Algorithms & Logic)

### 1. Find duplicate characters and unique characters in a string (Input: `weqjhjkAJKDbdnmbcnm`)?
**Solution**:
```java
Map<Character, Integer> map = new LinkedHashMap<>();
for(char c : s.toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);
map.forEach((k, v) -> {
    if(v > 1) System.out.println("Duplicate: " + k);
    else System.out.println("Unique: " + k);
});
```
