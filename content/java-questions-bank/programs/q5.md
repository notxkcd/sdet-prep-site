## Questions with Answers

## Beginner (Basics)

### 1. Reverse a string?
**Solution**:
```java
String rev = new StringBuilder(s).reverse().toString();
```

### 2. Reverse an integer number?
**Solution**:
```java
int rev = 0; while(n != 0) { rev = rev * 10 + n % 10; n /= 10; }
```

### 3. Count the number of letters in a given string (e.g., "Hello" -> 5)?
**Solution**:
```java
int count = s.length();
```

### 4. Factorial program?
**Solution**:
```java
int f=1; for(int i=1; i<=n; i++) f*=i;
```

### 5. Swap two variables without using a 3rd variable?
**Solution**:
```java
a = a + b; b = a - b; a = a - b;
```

### 6. Find the minimum and maximum value in a collection of numbers?
**Solution**:
```java
int min = Collections.min(list);
int max = Collections.max(list);
```

### 7. Check if a number is a Palindrome?
**Solution**:
```java
String s = String.valueOf(n);
boolean isPal = s.equals(new StringBuilder(s).reverse().toString());
```

### 8. Check if a string is a Palindrome?
**Solution**:
```java
boolean isPal = s.equals(new StringBuilder(s).reverse().toString());
```

### 9. Check if a number is a Prime number?
**Solution**:
```java
boolean isPrime = true;
for(int i=2; i*i<=n; i++) if(n%i==0) isPrime=false;
```

### 10. Write code to read data from a Property file?
**Solution**:
```java
Properties p = new Properties();
p.load(new FileInputStream("config.properties"));
String val = p.getProperty("key");
```

## Intermediate (Intermediate Logic)

### 1. Count vowels and non-vowels in a string?
**Solution**:
```java
int v=0, c=0;
for(char ch : s.toLowerCase().toCharArray()) {
    if("aeiou".indexOf(ch) != -1) v++; else if(ch>='a'&&ch<='z') c++;
}
```

### 2. Count the frequency of a letter in a string?
**Solution**:
```java
long freq = s.chars().filter(ch -> ch == 'a').count();
```

### 3. Fibonacci series?
**Solution**:
```java
int a=0, b=1; for(int i=0; i<10; i++) { System.out.print(a+" "); int n=a+b; a=b; b=n; }
```

### 4. Check if a number is an Armstrong number?
**Solution**:
```java
int sum=0, t=n; while(t>0){ int r=t%10; sum+=(r*r*r); t/=10; }
boolean isArm = (n == sum);
```

### 5. Sort an `ArrayList` in ascending order?
**Solution**:
```java
Collections.sort(list);
```

### 6. Separate numbers and alphabets from a mixed string?
**Solution**:
```java
String alph = s.replaceAll("[0-9]", "");
String num = s.replaceAll("[^0-9]", "");
```

### 7. Count digits of 'a' in a sentence?
**Solution**:
```java
long count = s.chars().filter(ch -> ch == 'a').count();
```

### 8. How to replace '.' with a space in an email only between names?
**Solution**:
```java
String namePart = s.substring(0, s.indexOf("@")).replace(".", " ");
String res = namePart + s.substring(s.indexOf("@"));
```

### 9. Reverse a string in different ways: "Deepak Kumar" -> "Kumar Deepak" (Swap words)?
**Solution**:
```java
String[] w = s.split(" ");
String res = w[1] + " " + w[0];
```

```java
class Book {
    Book(String author) { }
    Book(int id) { }
}
```

## Advanced (Algorithms & Complex Challenges)

### 1. Reverse each word in a string but keep the word position?
**Solution**:
```java
String[] words = s.split(" ");
String res = "";
for(String w : words) res += new StringBuilder(w).reverse() + " ";
```

### 2. Reverse a string (Input: "Deepak Kumar", Output: "kapeed ramuk")?
**Solution**:
```java
String res = new StringBuilder(s.toLowerCase()).reverse().toString();
```

### 3. Count the occurrence of each character in a string?
**Solution**:
```java
Map<Character, Integer> map = new HashMap<>();
for(char c : s.toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);
```

### 4. Remove all special characters from a string and print only alphanumeric characters?
**Solution**:
```java
String res = s.replaceAll("[^a-zA-Z0-9]", "");
```

### 5. Remove duplicates from a string without using Set or built-in methods?
**Solution**:
```java
String res = "";
for(char c : s.toCharArray()) if(res.indexOf(c) == -1) res += c;
```

### 6. Input: `String name = a2b3c2`, Output: `aabbbcc`?
**Solution**:
```java
for(int i=0; i<s.length(); i+=2) {
    char c = s.charAt(i);
    int count = Character.getNumericValue(s.charAt(i+1));
    for(int j=0; j<count; j++) System.out.print(c);
}
```

### 7. Sort a 2D array: `int[][]={{2,4,5},{3,4,7},{1,2,9}}`?
**Solution**:
```java
Arrays.sort(arr, (a, b) -> Integer.compare(a[0], b[0]));
```
