### 1. Write a Palindrome program?
**Solution**:
```java
String s = "madam";
String rev = new StringBuilder(s).reverse().toString();
boolean isPal = s.equals(rev);
```

## Intermediate

### 1. Input: `int [] = [1,0,0,2,0,0,0,3]`, Output: `[1,2,3,0,0,0]`. (Moving non-zero elements to the front)?
**Solution**:
```java
int[] arr = {1, 0, 0, 2, 0, 0, 0, 3};
int[] res = new int[arr.length];
int j = 0;
for(int x : arr) if(x != 0) res[j++] = x;
// res will be [1, 2, 3, 0, 0, 0, 0, 0]
```
