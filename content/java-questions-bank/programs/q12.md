## Questions with Answers

## Intermediate

### 1. Demonstrate Upcasting in a main method?
**Solution**:
```java
class Parent { void show() { System.out.println("Parent"); } }
class Child extends Parent { void show() { System.out.println("Child"); } }

public class Main {
    public static void main(String[] args) {
        Parent obj = new Child(); // Upcasting
        obj.show(); // Calls Child's method (Runtime Polymorphism)
    }
}
```

### 2. Demonstrate the use of `abstract` class and `private` fields with getters?
**Solution**:
```java
abstract class Vehicle {
    private String brand; // Encapsulation
    public Vehicle(String brand) { this.brand = brand; }
    public String getBrand() { return brand; } // Getter
    abstract void start(); // Abstraction
}
```

## Advanced

### 1. Write a program that demonstrates the four pillars of OOPS using an `Animal` superclass and a `Dog` subclass?
**Solution**:
```java
// 1. Abstraction
abstract class Animal {
    // 2. Encapsulation
    private String name;
    public Animal(String name) { this.name = name; }
    public String getName() { return name; }
    public abstract void makeSound();
}

// 3. Inheritance
class Dog extends Animal {
    public Dog(String name) { super(name); }
    // 4. Polymorphism (Overriding)
    @Override
    public void makeSound() {
        System.out.println(getName() + " says: Woof!");
    }
}
```
