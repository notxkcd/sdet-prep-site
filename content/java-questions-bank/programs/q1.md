## Questions with Answers

## Beginner (Basic Logic & Loops)

### 1. Swap two numbers using a temporary variable?
**Solution**:
```java
int a = 10, b = 20;
int temp = a;
a = b;
b = temp;
```

### 2. Write a code for String reverse?
**Solution**:
```java
String s = "Java";
String rev = new StringBuilder(s).reverse().toString();
```

### 3. Reverse a number in Java?
**Solution**:
```java
int n = 123, rev = 0;
while(n != 0) {
    rev = rev * 10 + n % 10;
    n /= 10;
}
```

### 4. Print "Infosys" but skip the letter "o"?
**Solution**:
```java
String s = "Infosys";
System.out.println(s.replace("o", ""));
```

### 5. How to replace a letter from a string?
**Solution**:
```java
String s = "apple";
String res = s.replace('a', 'b');
```

### 6. Replace vowels with `*` (Input: "chennai")?
**Solution**:
```java
String s = "chennai";
String res = s.replaceAll("[aeiouAEIOU]", "*");
```

### 7. Find the maximum and minimum values in an array?
**Solution**:
```java
int[] arr = {10, 5, 20};
int max = arr[0], min = arr[0];
for(int x : arr) {
    if(x > max) max = x;
    if(x < min) min = x;
}
```

### 8. Find the smallest value in an array?
**Solution**:
```java
int min = arr[0];
for(int x : arr) if(x < min) min = x;
```

### 9. Print all dividends of 8 between 1 and 100?
**Solution**:
```java
for(int i=1; i<=100; i++) if(i % 8 == 0) System.out.println(i);
```

### 10. Sum the integers found in a mixed string?
**Solution**:
```java
String s = "1a2b3c";
int sum = 0;
for(char c : s.toCharArray()) {
    if(Character.isDigit(c)) sum += Character.getNumericValue(c);
}
```

### 11. Write a code for Palindrome?
**Solution**:
```java
String rev = new StringBuilder(str).reverse().toString();
boolean isPal = str.equals(rev);
```

## Intermediate (Intermediate Strings, Arrays & Logical Reasoning)

### 1. Swap two variables without using a 3rd variable?
**Solution**:
```java
int a = 10, b = 20;
a = a + b;
b = a - b;
a = a - b;
```

### 2. Fibonacci series code?
**Solution**:
```java
int a = 0, b = 1;
for(int i=0; i<10; i++) {
    System.out.print(a + " ");
    int next = a + b;
    a = b;
    b = next;
}
```

### 3. Write a sorting program?
**Solution**:
```java
int[] arr = {5, 2, 8, 1};
Arrays.sort(arr);
```

### 4. Find the second maximum value in an array?
**Solution**:
```java
Arrays.sort(arr);
int secondMax = arr[arr.length - 2];
```

### 5. Find the second largest number in an array?
**Solution**:
```java
// Same as second maximum
Arrays.sort(arr);
int res = arr[arr.length - 2];
```

### 6. Find duplicate numbers in an array?
**Solution**:
```java
Set<Integer> set = new HashSet<>();
for(int x : arr) if(!set.add(x)) System.out.println(x);
```

### 7. Find the maximum salary of an individual in an array?
**Solution**:
```java
int max = Arrays.stream(salaries).max().getAsInt();
```

### 8. Count the occurrence of a character in a string?
**Solution**:
```java
long count = s.chars().filter(c -> c == 'a').count();
```

### 9. Find the occurrence of a substring in a string?
**Solution**:
```java
int count = (s.split(sub, -1).length) - 1;
```

### 10. How to replace multiple letters from a string using the same `replace` method?
**Solution**:
```java
String res = s.replace("a", "*").replace("e", "*");
```

### 11. Separate String and Integer from a mixed list or array?
**Solution**:
```java
for(Object o : list) {
    if(o instanceof Integer) // add to int list
    else if(o instanceof String) // add to string list
}
```

### 12. Reverse the words in a string (Input: "test program")?
**Solution**:
```java
String[] w = "test program".split(" ");
String res = w[1] + " " + w[0];
```

### 13. Format a string (Input: "xperience", Output: "xp*ri*nc**")?
**Solution**:
```java
String s = "xperience";
String res = s.replaceAll("[aeiou]", "*");
```

### 14. Extract ABC and 123 from "AB12C3" and print "ABC123"?
**Solution**:
```java
String s = "AB12C3";
String alph = s.replaceAll("[0-9]", "");
String num = s.replaceAll("[^0-9]", "");
System.out.println(alph + num);
```

### 15. Input: `Same`, Output: `Saammmeeee`?
**Solution**:
```java
String s = "Same", res = "";
for(int i=0; i<s.length(); i++) {
    for(int j=0; j<=i; j++) res += s.charAt(i);
}
```

## Advanced (Advanced Algorithms, Complex Manipulations & Optimization)

### 1. Check if two strings are Anagram or not?
**Solution**:
```java
char[] c1 = s1.toLowerCase().toCharArray();
char[] c2 = s2.toLowerCase().toCharArray();
Arrays.sort(c1);
Arrays.sort(c2);
boolean isAnagram = Arrays.equals(c1, c2);
```

### 2. Reverse each word in a given string without changing the caps and small letters?
**Solution**:
```java
String[] words = s.split(" ");
String res = "";
for(String w : words) res += new StringBuilder(w).reverse() + " ";
```

### 3. Find character count and duplicate characters in a string array?
**Solution**:
```java
Map<String, Integer> map = new HashMap<>();
for(String s : arr) map.put(s, map.getOrDefault(s, 0) + 1);
```

### 4. Remove duplicates from a string and print unique values (Input: "giggling")?
**Solution**:
```java
String res = "";
for(char c : s.toCharArray()) if(res.indexOf(c) == -1) res += c;
```

### 5. Remove duplicates in a long list of integers/strings?
**Solution**:
```java
Set<T> unique = new LinkedHashSet<>(list);
```

### 6. Count words greater than 5 and reverse only those?
**Solution**:
```java
String[] words = s.split(" ");
for(int i=0; i<words.length; i++) {
    if(words[i].length() > 5) words[i] = new StringBuilder(words[i]).reverse().toString();
}
```

### 7. Split letters and numbers from a string and print them separately?
**Solution**:
```java
System.out.println(s.replaceAll("[0-9]", ""));
System.out.println(s.replaceAll("[^0-9]", ""));
```

### 8. Print the frequency of integers and letters in a mixed string?
**Solution**:
```java
Map<Character, Integer> freq = new HashMap<>();
for(char c : s.toCharArray()) freq.put(c, freq.getOrDefault(c, 0) + 1);
```

### 9. Array rotational coding?
**Solution**:
```java
// Rotate left by 1
int first = arr[0];
for(int i=0; i<arr.length-1; i++) arr[i] = arr[i+1];
arr[arr.length-1] = first;
```

### 10. Sum the numbers in a mixed array (e.g., from `1,2,3,a,b,c` sum `1,2,3`)?
**Solution**:
```java
int sum = 0;
for(Object o : arr) if(o instanceof Integer) sum += (Integer)o;
```

### 11. Find the occurrence of a specific number in a long sequence?
**Solution**:
```java
long count = Arrays.stream(arr).filter(x -> x == target).count();
```

### 12. Transpose a 2D array?
**Solution**:
```java
for(int i=0; i<rows; i++)
    for(int j=0; j<cols; j++) transpose[j][i] = matrix[i][j];
```

### 13. Declare a 2D array and perform operations?
**Solution**:
```java
int[][] matrix = {{1, 2}, {3, 4}};
```

### 14. Input: `int [] = [1,0,0,2,0,0,0,3]`, Output: `[1,2,3,0,0,0]`?
**Solution**:
```java
int[] res = new int[arr.length];
int j = 0;
for(int x : arr) if(x != 0) res[j++] = x;
```

### 15. Input: `a (1,2,3,a,b,c)`, Task: Remove (a b c) and sum (1 2 3)?
**Solution**:
```java
int sum = 0;
for(Object o : list) if(o instanceof Integer) sum += (Integer)o;
```
