Problem 3 — Factorial using loop

int n = 5;
int result = 1;
for (int i = 1; i <= n; i++) {
    result = result * i;
}

Trace: i=1, res=1 -> i=2, res=2 -> i=3, res=6 -> i=4, res=24 -> i=5, res=120.

Problem 5 — Array Sum & Avg

int[] arr = {2, 4, 6, 8};
int sum = 0;
for(int x : arr) sum += x;
double avg = (double) sum / arr.length;

Trace: sum=0 -> 2 -> 6 -> 12 -> 20. Avg = 20/4 = 5.0.

Problem 6 — Count Vowels

String s = "hello";
int count = 0;
for(char c : s.toCharArray()) {
    if("aeiou".indexOf(c) != -1) count++;
}

Trace: ‘h’ (no), ’e’ (yes, count=1), ’l’ (no), ’l’ (no), ‘o’ (yes, count=2).
