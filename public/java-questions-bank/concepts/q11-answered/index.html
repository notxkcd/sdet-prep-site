Java Concept Study Guide - Java Q_Set_1_and_2

Java Concept Study Guide - Java Q_Set_1_and_2

Beginner (Fundamentals)

1. What is the use of the main method in Java?

Answer: It is the entry point of any Java program. JVM starts execution from public static void main(String[] args).

2. Difference between a class and an object?

Answer: A Class is a blueprint/design; an Object is a physical instance of that class.

3. What is the Scanner class?

Answer: A built-in class used to capture user input from the console.

4. Difference between .java and .class files?

Answer:

  • .java: The source code file written by us.
  • .class: The compiled bytecode file generated by the compiler (javac).

5. Difference between a class and a method.

Answer: A Class is a blueprint for objects; a Method is a block of code inside a class that performs an action.

6. What is a Wrapper class?

Answer: Classes that convert primitive data types into objects (e.g., int -> Integer). This allows using primitives in Collections.

7. What is the new keyword?

Answer: Used to create an object and allocate memory on the heap.

8. What are the main differences between C, C++, and Java?

Answer: C is procedural; C++ is object-oriented with pointers; Java is fully object-oriented, platform-independent, and manages memory automatically (no pointers).

9. What is a constructor and why is it used?

Answer: A special method to initialize objects. It sets the initial state of the object when it is created.

10. What is an Interface?

Answer: A contract that defines what a class should do, without defining how. It contains abstract methods.

11. Access modifiers and their scopes (Public, Private, Protected, Default).

Answer:

  • Public: Anywhere.
  • Private: Class only.
  • Protected: Package + Subclasses.
  • Default: Package only.

12. Difference between while and do-while loops?

Answer: while checks condition first; do-while executes once then checks.

13. Primitives vs. Non-Primitive data types.

Answer: Primitives (int, char) store values; Non-Primitives (String, Array) are objects and store references.

Intermediate (Differences & Practical Logic)

14. Explain the OOPS concepts (Inheritance, Polymorphism, Encapsulation, Abstraction).

Answer:

  • Inheritance: Code reuse from parent.
  • Polymorphism: Same action, multiple forms.
  • Encapsulation: Hiding data for security.
  • Abstraction: Hiding implementation details.

15. Difference between an Abstract Class and an Interface.

Answer: Abstract classes can have state and implemented methods; Interfaces are contracts (purely abstract until Java 8).

16. Difference between Abstraction and Encapsulation.

Answer: Abstraction hides complexity; Encapsulation protects data.

17. this vs. super keyword.

Answer: this refers to the current object; super refers to the parent object.

18. Difference between final, finally, and finalize?

Answer: final is a restriction; finally is a cleanup block; finalize is for GC cleanup.

19. Difference between default and protected.

Answer: default is only visible within the same package; protected is visible in the package and in subclasses outside the package.

20. Why is String immutable in Java?

Answer: For Security, Memory Saving (String Pool), and Thread Safety.

21. Difference between StringBuffer and StringBuilder.

Answer: StringBuffer is thread-safe; StringBuilder is faster but not thread-safe.

22. Difference between String s = “abc” and String s = new String(“abc”).

Answer: First uses String Pool; second creates a new object on the heap.

23. Difference between Array and ArrayList.

Answer: Array is fixed-size; ArrayList is dynamic-sized.

24. Difference between List and Set.

Answer: List allows duplicates and keeps order; Set prohibits duplicates and is unordered.

25. Difference between List and Map.

Answer: List is a sequence of elements; Map is key-value pairs.

26. Difference between HashMap and HashTable?

Answer: HashMap is not synchronized and allows nulls; HashTable is synchronized and disallows nulls.

27. What is Inheritance? Can we use inheritance in Interface?

Answer: Mechanism to inherit properties. Interfaces can extend other interfaces using extends.

28. Explain Exception handling in Java.

Answer: Managing runtime errors using try, catch, finally, throw, and throws.

29. Difference between checked and unchecked exceptions.

Answer: Checked are compile-time (forced handle); Unchecked are runtime (logic errors).

Advanced (Internal Mechanics & Complex Scenarios)

30. What is the Object class? Name some of its methods.

Answer: The root class of Java. Methods: toString(), equals(), hashCode(), wait(), notify().

31. What is polymorphism? Explain Static and Dynamic polymorphism.

Answer: One thing, many forms. Static (Overloading) is compile-time; Dynamic (Overriding) is runtime.

32. Can you execute a method without a main method?

Answer: Yes, using a static block (pre-Java 7) or a testing framework like TestNG.

33. What is a Copy Constructor?

Answer: Initializes an object using another object of the same class.

34. What is Constructor Chaining?

Answer: Calling one constructor from another using this() or super().

35. Can we use static methods in a constructor?

Answer: Yes, but they don’t depend on the instance being created.

36. Dependency Injection via Constructor.

Answer: Passing dependent objects (like WebDriver) into a class through its constructor.

37. What happens if an interface is implemented but a method is not given a body?

Answer: The implementing class must be declared abstract.

38. Can we write non-abstract methods in an Interface?

Answer: Yes, since Java 8 using default or static keywords.

39. Can we create a constructor for an Abstract Class?

Answer: Yes, it is called when a child class object is created.

40. Can we create an object of a fully abstract class?

Answer: No, abstract classes cannot be instantiated.

41. What is Multiple Inheritance and why is it handled via Interfaces in Java?

Answer: Inheriting from more than one class. Java avoids the “Diamond Problem” by only allowing it via Interfaces.

42. How do you implement Hybrid Inheritance?

Answer: A combination of two or more types of inheritance, achieved in Java using a mix of classes and interfaces.

43. Explain Multilevel Inheritance.

Answer: A chain of inheritance where a class extends a child class (A -> B -> C).

44. What happens if the static keyword is missing from the main method?

Answer: The JVM won’t recognize it as the entry point and will throw a runtime error.

45. How does a HashMap work internally?

Answer: Uses hashing to store key-value pairs in buckets. Uses hashCode() to find bucket and equals() to find key in case of collisions.

46. How do you convert a HashMap to an Array?

Answer: Use map.values().toArray() or map.keySet().toArray().

47. What is Serialization in Java?

Answer: Converting an object into a byte stream for storage or transmission.
