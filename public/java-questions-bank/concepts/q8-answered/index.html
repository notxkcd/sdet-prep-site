Beginner (Basics)

1. Explain the OOPS concepts.

Answer:

  • Inheritance: Reuse code from parent.
  • Polymorphism: One name, many forms.
  • Encapsulation: Secure data in a unit.
  • Abstraction: Show essential features.

2. What are the access specifiers in Java?

Answer: public (anywhere), private (class only), protected (package + child), default (package only).

3. Difference between JDK and JRE.

Answer: JRE (Runtime) runs the programs; JDK (Development Kit) contains tools like compiler (javac) to create programs.

4. How do you read input in Java?

Answer: Using the Scanner class from java.util. Example: Scanner s = new Scanner(System.in); s.next();.

5. Is TakesScreenshot a class or an interface in Selenium?

Answer: It is an Interface.

Intermediate (Differences & Practical Logic)

6. What are the differences between an Abstract Class and an Interface?

Answer: Abstract classes can have state and shared implementation; Interfaces are behavior blueprints (mostly abstract).

7. What is the difference between Method Overloading and Method Overriding?

Answer: Overloading is same class (different parameters); Overriding is parent/child relationship (same parameters).

8. What is the difference between final and finally?

Answer: final is a keyword for constants/restrictions; finally is a block for guaranteed cleanup code.

9. What is the difference between a List and a Set?

Answer: List maintains order and allows duplicates; Set is unordered and unique.

10. Explain the Java Collection framework.

Answer: A hierarchy of interfaces and classes to store and process a group of objects.

11. Explain the HashMap in detail.

Answer: A collection that stores data in key-value pairs using a hashing algorithm for fast retrieval.

12. What is the difference between a Collection and a Set?

Answer: Collection is the root interface; Set is a sub-interface that enforces uniqueness.

13. Is JavaScript a class or an interface?

Answer: In Java/Selenium, JavascriptExecutor is an Interface.

Advanced (Internal Mechanics & Complex Scenarios)

14. Explain the difference between Static Binding and Dynamic Binding.

Answer: Static Binding (Early) happens at compile-time (e.g., static methods); Dynamic Binding (Late) happens at run-time (e.g., overridden methods).

15. What is Compile-time Polymorphism?

Answer: Another name for Method Overloading, where the compiler decides which method to call.

16. Can a static method be overridden?

Answer: No. Static methods are hidden (Method Hiding), not overridden.

17. What is synchronization in Java and how do you handle it?

Answer: It prevents multiple threads from accessing a resource simultaneously. Handled using the synchronized keyword.

18. Write the code for using entrySet() in a Map.

Answer:

for (Map.Entry<String, String> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " = " + entry.getValue());
}
