Java Concept Study Guide - OOPS

Java Concept Study Guide - OOPS

Beginner (Fundamentals)

1. What is OOPS?

Answer: Object-Oriented Programming (OOPS) is a paradigm that uses “objects” to design software, focusing on data and its interactions to solve problems.

2. What is the difference between a Class and an Object?

Answer: A Class is a blueprint/template; an Object is a physical instance of that blueprint.

3. Explain the “four pillars” of OOPS:

Answer:

  • Encapsulation: Data hiding and bundling.
  • Inheritance: Code reuse via parent-child relationship.
  • Polymorphism: One thing having many forms.
  • Abstraction: Showing only essential features.

4. What is the syntax for declaring, initializing, and accessing arrays in Java?

Answer:

  • Declare: int[] arr;
  • Init: arr = new int[5];
  • Access: int x = arr[0];

5. What is the difference between an Abstract Class and an Interface?

Answer: Abstract classes can have implemented methods and state; Interfaces are purely behavioral blueprints (contracts).

Intermediate (Practical Concepts & Implementation)

6. Explain the key principles of OOPS (Modularity, Reusability, Scalability, Real-World Modeling, Security).

Answer:

  • Modularity: Organizing code into independent units.
  • Reusability: Using existing code for new tasks.
  • Scalability: Easily expanding the system.
  • Real-World Modeling: Mapping real objects to software objects.
  • Security: Protecting data via encapsulation.

7. How is OOPS implemented in Java specifically?

Answer: Through classes, interfaces, access modifiers, and keywords like extends, implements, abstract.

8. What are the types of Inheritance supported in Java?

Answer: Single, Multilevel, and Hierarchical. Multiple inheritance is only supported via Interfaces.

9. Explain the difference between Compile-time (Overloading) and Run-time (Overriding) Polymorphism.

Answer: Overloading is decided by the compiler (same name, diff params); Overriding is decided at runtime (same name, same params in parent/child).

10. What is the difference between a String Literal and a Non-Literal String?

Answer: Literal goes to the String Pool; Non-Literal (new) always creates a new object on the Heap.

11. Explain why Strings are immutable and how it relates to encapsulation.

Answer: Immutability ensures that the string’s value cannot be changed, protecting the data (encapsulation) and allowing safe sharing in memory.

Advanced (Internal Mechanics & Scenarios)

12. Explain the difference between Association, Aggregation, and Composition.

Answer: Association is any relationship; Aggregation is a weak “has-a” (parts can exist separately); Composition is a strong “has-a” (parts die with the whole).

13. What is Type Casting? Explain Upcasting and Downcasting with examples.

Answer: Upcasting is subclass to superclass (e.g., Animal a = new Dog();); Downcasting is superclass to subclass (e.g., Dog d = (Dog) a;).

14. Explain how OOPS concepts are applied in a Selenium automation framework.

Answer: Encapsulation in POM; Inheritance in Base classes; Polymorphism in WebDriver setup; Abstraction in element interaction interfaces.

15. How does the String Pool work in Java?

Answer: It is a cache of string objects in memory. Literal strings are reused from this pool if they already exist, saving memory.

16. How can arrays be used to demonstrate polymorphism?

Answer: An array of a superclass type can hold objects of any of its subclasses (e.g., Animal[] arr = {new Dog(), new Cat()};).
