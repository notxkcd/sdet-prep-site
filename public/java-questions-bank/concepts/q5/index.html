Questions with Answers

Beginner (Basics)

1. Provide examples of Abstraction, Interface, and Encapsulation?

Answer:

  • Abstraction: A BasePage defining a generic login() flow.
  • Interface: WebDriver defining actions like get(), close().
  • Encapsulation: Using private By locator and providing a public clickElement() method.

2. Explain Inheritance and its types?

Answer: Mechanism where a class acquires properties of another. Types: Single (A->B), Multilevel (A->B->C), Hierarchical (A->B, A->C).

3. What are the Access Modifiers and their scopes?

Answer: public (anywhere), private (class only), protected (package + child), default (package only).

Intermediate (Practical Implementation & Differences)

1. How do you use Abstract classes in your project?

Answer: To create a template for all page objects (e.g., BasePage) that holds the common WebDriver instance and utility methods.

2. How do you use Interfaces in your project?

Answer: To define standard behaviors across different classes (e.g., a UIElement interface) or to utilize built-in Selenium interfaces like WebElement.

3. Difference between List and Set?

Answer: List is ordered and allows duplicate elements; Set is unordered and prohibits duplicates.

4. Explain the difference between final, finally, and finalize?

Answer: final is for constants/restrictions; finally is a block for guaranteed cleanup; finalize is for GC cleanup logic.

5. What is the difference between Literal and Non-Literal Strings?

Answer: Literal ("abc") uses the String Pool for memory efficiency; Non-literal (new String("abc")) always creates a new object on the heap.

Advanced (Internal Mechanics & Scenarios)

1. Explain the Garbage Collector in Java?

Answer: An automatic process that manages memory by finding and deleting unreachable objects, freeing up space on the heap.

2. Where have you implemented Method Overloading and Method Overriding in your project?

Answer:

  • Overloading: Generic methods like waitForElement(locator) and waitForElement(locator, timeout).
  • Overriding: Subclass pages redefining isLoaded() or submit() methods from the BasePage.
