Beginner (Basics)

1. What is a Variable?

Answer: A container that holds data during the execution of a program (e.g., int x = 10;).

2. Difference between Local and Global variables.

Answer:

  • Local: Declared inside a method; visible only within that method.
  • Global (Instance): Declared inside a class but outside methods; visible to all methods in the class.

3. Explain Looping statements.

Answer: Statements that execute a block of code repeatedly as long as a condition is true (e.g., for, while, do-while).

4. Explain Conditional statements.

Answer: Statements used to make decisions based on conditions (e.g., if, else if, switch).

5. What is the syntax for if-else conditions?

Answer:

if (condition) {
    // executes if true
} else {
    // executes if false
}

6. What are the uses of a Constructor?

Answer: To initialize the state of an object and allocate memory when it is created.

7. Difference between == and .equals().

Answer: == compares the reference (memory address); .equals() compares the content or value.

Intermediate (Conceptual Implementation)

8. What is the difference between an Abstract Class and an Interface?

Answer: Abstract classes can have state and implemented methods; Interfaces are blueprints of behavior (pure contracts).

9. Why do we use an Interface?

Answer: To achieve 100% abstraction and to support multiple inheritance of behavior.

10. What is the difference between Method Overloading and Method Overriding?

Answer: Overloading is same name, different parameters (same class); Overriding is same name, same parameters (parent/child relationship).

11. What is a Constructor and how is it used in your framework?

Answer: A special method to initialize objects. Used in frameworks to initialize the WebDriver instance or page objects.

12. Explain Inheritance and how it is implemented in your project.

Answer: A mechanism to reuse code from a parent class. Implemented by extending a BasePage or BaseTest class.

13. How can you call a static variable from another class?

Answer: By using the class name: ClassName.variableName;.

14. Difference between StringBuffer and StringBuilder.

Answer: StringBuffer is synchronized (thread-safe); StringBuilder is faster (non-thread-safe).

15. Explain Collections concept in general.

Answer: A framework that provides a common architecture to store and manipulate groups of objects.

Advanced (Internal & Project Specific)

16. Where do you use Overloading and Overriding in your automation framework?

Answer: Overloading for generic utility methods (e.g., click(element) vs click(locator)); Overriding for custom page-specific behaviors.

17. How can you access all methods of Class A in Class B?

Answer: By making Class B extend Class A (class B extends A).

18. If you have multiple methods, how do you handle the return statements?

Answer: Each method must return a type matching its signature, using the return keyword to pass data back to the caller.

19. What is a Linked List and where have you used it in your project?

Answer: A dynamic data structure where each element points to the next. Used when frequent insertions and deletions are needed.

20. How do you throw a custom exception?

Answer: Create a class that extends Exception, then use the throw keyword:

class MyException extends Exception { ... }
throw new MyException("Error message");
