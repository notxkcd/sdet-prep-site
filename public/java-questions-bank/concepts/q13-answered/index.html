Java Ecosystem (TestNG) Concept Study Guide - TestNG_QuestionDump_Set_1_2_3

Beginner

1. What is TestNG and explain why and where it is required?

Answer: TestNG is a testing framework inspired by JUnit but introducing new functionalities like grouping, parameterization, and dependency testing. It is required for sophisticated automation suites where test control is essential.

2. What are the advantages of TestNG?

Answer: Support for annotations, data-driven testing (via @DataProvider), parallel execution, prioritizing tests, and generating detailed HTML reports.

3. List TestNG annotations and explain their execution order.

Answer:

  1. @BeforeSuite, 2. @BeforeTest, 3. @BeforeClass, 4. @BeforeMethod, 5. @Test, 6. @AfterMethod, 7. @AfterClass, 8. @AfterTest, 9. @AfterSuite.

Intermediate

4. What is the use of testng.xml and what is the sequence used in it?

Answer: It is used to configure and run the entire test suite. The sequence is: <suite> -> <test> -> <classes> -> <class> -> <methods>.

5. What is a Data Provider in TestNG?

Answer: A method that provides an array of objects to a test method, allowing the test to run multiple times with different data inputs.

6. How do you rerun failed test cases in TestNG?

Answer: By running the testng-failed.xml file created in the test-output folder, or by implementing the IRetryAnalyzer interface for automatic retries.

7. How do you perform parameterization in TestNG?

Answer: Using the @Parameters annotation (reading from testng.xml) or using @DataProvider (reading from code/external files).

8. How do you generate reports in TestNG?

Answer: TestNG automatically generates HTML and XML reports in the test-output folder after execution. Custom reports can be made using ITestListener or IReporter.

9. How do you pass test data in TestNG?

Answer: Primarily through @DataProvider or by passing parameters via the testng.xml file.

10. How do you set priority in TestNG? What happens if no priority is set?

Answer: Use the priority attribute in @Test(priority = 1). If not set, tests run in alphabetical order.

11. How can you ignore or skip a particular test case in TestNG?

Answer: Use @Test(enabled = false) to ignore, or throw a SkipException to skip during runtime.

12. How do you run a particular method multiple times in TestNG?

Answer: Use the invocationCount attribute: @Test(invocationCount = 10).

13. Why choose TestNG over other frameworks like JUnit or Cucumber?

Answer: It offers more control over execution (priority, groups, parallel) compared to JUnit, and is easier to set up for technical testing than Cucumber (which focuses on BDD).

Advanced

14. How do you perform parallel execution in TestNG?

Answer: In testng.xml, use the parallel attribute in the <suite> tag (set to methods, tests, or classes) and define the thread-count.

15. Explain the priority logic when some tests have priority and others do not.

Answer: Priority 0 is the default. Tests with negative priority run first, followed by priority 0 (alphabetical), then positive priorities.
