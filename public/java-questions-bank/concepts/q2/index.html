Questions with Answers

Beginner (Basics)

1. What is the difference between a class and an object?

Answer: A Class is a blueprint or template (e.g., a Car design). An Object is a real-world instance of that class (e.g., your actual car).

2. What are Primitives and Non-Primitive data types?

Answer: Primitives (e.g., int, char) store simple values directly. Non-Primitives (e.g., String, Array) are complex objects and store references.

3. Is String a primitive or non-primitive data type? Is it a class or a data type?

Answer: It is a Non-primitive type and a Class in Java.

4. What are the different types of variables in Java?

Answer:

  • Static: Shared by all objects of the class.
  • Instance: Unique to each object instance.
  • Local: Declared inside a method or block.

5. What is an Interface?

Answer: A blueprint of behavior that a class must implement; it defines a contract of “what” to do.

6. What is the keyword used to implement an interface?

Answer: implements.

7. What are Wrapper classes and why are they used?

Answer: They wrap primitives into objects (e.g., int to Integer). Used to allow primitives in Collections like ArrayList.

8. What is the break keyword and why is it used?

Answer: Used to exit a loop or a switch statement immediately.

9. What is the output of System.out.println(2 + 3 + "HELLO")?

Answer: 5HELLO. Math is done first, then string concatenation.

10. What is the “super head” of all classes?

Answer: The Object class.

Intermediate (Implementation & Logical Differences)

1. Explain OOPS concepts in detail?

Answer: Encapsulation (hiding data), Inheritance (reusing code), Polymorphism (multiple forms), and Abstraction (hiding complexity).

2. Difference between Method Overloading and Method Overriding?

Answer: Overloading is same class, diff parameters (Compile-time). Overriding is parent/child, same parameters (Runtime).

3. Explain Inheritance and the types of inheritance?

Answer: Child class acquires parent properties. Types: Single, Multilevel, Hierarchical.

4. Difference between Abstraction and Encapsulation?

Answer: Abstraction hides implementation; Encapsulation hides data (using private).

5. What is the difference between this and super keywords?

Answer: this refers to the current class instance; super refers to the parent class instance.

6. What is a Constructor? Why do we need one in a project?

Answer: A special method to initialize objects. Needed to set initial values or pass dependencies (like WebDriver).

7. Access Modifiers: Scope and differences?

Answer: public (anywhere), private (class only), protected (package+child), default (package).

8. What is the scope of a private method?

Answer: Only accessible within the class it is declared in.

9. How do you use a private variable in another class?

Answer: Using public Getter and Setter methods.

10. String is immutable. How do you change or update a string value?

Answer: Using StringBuilder or StringBuffer, or by creating a new String reference.

11. Difference between == and .equals()?

Answer: == compares references (memory); .equals() compares content (values).

12. Difference between StringBuffer and StringBuilder?

Answer: StringBuffer is thread-safe (slower); StringBuilder is not (faster).

13. What is the difference between List, Set, and Map?

Answer: List (ordered, duplicates), Set (unordered, unique), Map (key-value pairs).

14. Difference between Array and ArrayList?

Answer: Array is fixed-size; ArrayList is dynamic-sized.

15. What are Collections in Java?

Answer: A framework that provides classes and interfaces to store and manipulate groups of objects.

16. What is a HashMap?

Answer: A collection that stores data in key-value pairs for fast retrieval.

17. Explain Exception and its types?

Answer: Events that disrupt code flow. Types: Checked (compile-time) and Unchecked (runtime).

18. Difference between final, finally, and finalize?

Answer: final (constant), finally (block for cleanup), finalize (GC cleanup method).

19. Can we change a variable once it’s declared final?

Answer: No, it becomes a constant.

Advanced (Deep Dives & Scenario Based)

1. Explain Polymorphism (Static vs. Dynamic)?

Answer: Static is Overloading (decided at compile-time); Dynamic is Overriding (decided at run-time).

2. Why is Multiple Inheritance not supported in Java?

Answer: To avoid the “Diamond Problem” (ambiguity between parents). Achieved via Interfaces.

3. Can we have multiple constructors in the same class?

Answer: Yes, this is called Constructor Overloading.

4. Can an abstract method be final?

Answer: No, because abstract requires overriding, and final prevents it.

5. Can an abstract class contain a final method?

Answer: Yes, to provide a common implementation that cannot be changed by subclasses.

6. What is a Static block?

Answer: Code that runs once when the class is first loaded by the JVM.

7. What is a Functional Interface and a Lambda Expression?

Answer: Functional Interface has one abstract method. Lambda is a concise way to implement it.

8. What is Serialization in Java?

Answer: Converting an object into a byte stream for storage or transmission.

9. Can a final method be overridden?

Answer: No.

10. How do you troubleshoot an exception?

Answer: Check the stack trace to find the exception type and the specific line number in your code.

11. Can we store objects in a HashMap and how do we retrieve them?

Answer: Yes. Retrieve using map.get(keyObject).

12. Does Map allow null values?

Answer: HashMap allows one null key and multiple null values.

13. How do you initialize a HashMap?

Answer: Map<String, String> map = new HashMap<>();
