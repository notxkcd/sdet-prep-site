Questions with Answers

Introduction & Experience - Answers

1. Self Introduction / Brief Introduction / Tell me about yourself?

Answer: I am Mohammed Shahid, an Automation Tester with 2.5 years of experience in Software Testing. I specialize in developing robust Selenium WebDriver scripts using Java. I have worked extensively with BDD (Cucumber) and TDD (TestNG/JUnit) frameworks. My recent project was “IntelliLearn” for Learning Links Foundation, where I implemented CI/CD pipelines using Jenkins and managed version control with Git. I hold a B.Tech in IT from the Info Institute of Engineering.

2. How many years of experience do you have in automation?

Answer: I have 2.5 years of professional experience in software testing, with a primary focus on automation testing using Selenium and Java.

3. Explain your experience and how you work on your projects?

Answer: I follow the full SDLC and STLC using Agile Scrum methodologies. In my projects, I analyze functional specifications, design test cases, and develop automated scripts using the Page Object Model (POM). I integrate these tests into Jenkins for CI/CD and participate in daily scrums, sprint reviews, and retrospectives to ensure quality and timely delivery.

4. What are your roles and responsibilities?

Answer: My responsibilities include:

  • Analyzing requirements and user workflows.
  • Designing and executing functional, regression, and usability test cases.
  • Developing and maintaining UI automation scripts using Selenium and Maven.
  • Managing bug tracking and documentation in JIRA.
  • Performing exploratory testing to uncover edge cases.

5. Tell me about your framework?

Answer: I work with a Maven-based hybrid framework. It uses Cucumber for BDD scenarios, Selenium WebDriver for UI interactions, and TestNG for execution and assertions. I follow the Page Object Model (POM) design pattern to ensure script maintainability and reuse.

6. What build tools do you have real-time experience with (e.g., Maven)?

Answer: I have hands-on experience with Maven for build automation and dependency management.

Answer: Yes, I have implemented Continuous Integration by integrating my Selenium automation frameworks with Jenkins.

6. Do you have experience with Linux?

Answer: Yes, I am skilled in performing cross-browser testing across different operating systems, including Windows and Linux.

7. Do you have team lead experience?

Challenges & Problem Solving - Answers

1. What challenges have you faced in your automation framework?

Answer: One common challenge was handling dynamic web elements and synchronization issues. I overcame this by implementing robust explicit waits and refining my XPath/CSS selectors using axes. Another challenge was managing large test data sets, which I resolved by implementing a data-driven approach using Excel and Apache POI.

2. What are the common challenges you face in automation/testing?

Answer: Challenges include test flakiness, environment instability, and frequent UI changes. I address these by writing modular code, using stable locators, and maintaining a healthy regression suite that is updated alongside development.

3. Tell me about a challenge you faced in your last project and how you overcame it?

Answer: In the IntelliLearn project, the application adapted automatically to individual student levels, creating dynamic learning paths. This made static testing difficult. I overcame this by creating dynamic automation scripts that could adapt to different user roles (teachers/students) and validate content alignment across various syllabus-based paths.

4. Challenges in understanding acceptance criteria?

Answer: Sometimes criteria were vague. I resolved this by initiating discussions during Backlog Refinement or Sprint Planning meetings to ensure 100% clarity before starting script development.

5. Challenges shared in Agile meetings and how they improved?

Answer: During a Sprint Retrospective, I highlighted that delayed test data setup was slowing down execution. The team improved this by creating shared SQL scripts to automate the test data injection process at the start of each sprint.

Behavioral & Personal - Answers

3. What is your expected salary?

Answer: I am open to a competitive offer that is consistent with my 2.5 years of specialized automation experience and the industry standards for an SDET/Automation Tester role.
