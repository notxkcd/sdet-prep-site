Intermediate

1. Write a program to convert a HashMap to an Array.

Solution:

String[] arr = map.values().toArray(new String[0]);

Advanced

2. Write a program using a HashMap to find the number of occurrences of each character in a string.

Solution:

Map<Character, Integer> map = new HashMap<>();
for(char c : s.toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);
