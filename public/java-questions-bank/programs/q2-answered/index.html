Beginner (Basic Manipulations & Logic)

1. Reverse a string (Input: inte*#rview*#).

Solution:

String s = "inte*#rview*#";
String rev = new StringBuilder(s).reverse().toString();

2. Remove spaces from a string.

Solution:

String s = "Hello World";
s = s.replaceAll("\\s", "");

3. Print vowels in a given string.

Solution:

String s = "my name is gyan";
for(char c : s.toCharArray()) if("aeiou".indexOf(c) != -1) System.out.println(c);

4. Check if a number is even or odd.

Solution:

if(n % 2 == 0) System.out.println("Even"); else System.out.println("Odd");

5. Swap two numbers without using a third variable.

Solution:

a = a + b; b = a - b; a = a - b;

6. Check if a number is Prime or not.

Solution:

boolean isPrime = true;
for(int i=2; i<=n/2; i++) if(n % i == 0) { isPrime = false; break; }

7. Fibonacci series.

Solution:

int a=0, b=1;
for(int i=0; i<10; i++) { System.out.print(a + " "); int sum = a+b; a=b; b=sum; }

Intermediate (Intermediate Logic & Data Structures)

9. Check if a string is a Palindrome or not.

Solution:

boolean isPal = s.equals(new StringBuilder(s).reverse().toString());

10. Count the occurrence of a character.

Solution:

long count = s.chars().filter(ch -> ch == 'a').count();

11. Find the second largest number in an array.

Solution:

Arrays.sort(arr);
int secondMax = arr[arr.length - 2];

12. Find duplicate numbers in an array.

Solution:

Set<Integer> set = new HashSet<>();
for(int x : arr) if(!set.add(x)) System.out.println(x);

Advanced (Advanced Algorithms & Tricky Logic)

13. Remove special characters from a string without using a loop.

Solution:

String res = s.replaceAll("[^a-zA-Z0-9]", "");

14. Separate characters, special characters, and digits from a string.

Solution:

String alph = s.replaceAll("[^a-zA-Z]", "");
String digits = s.replaceAll("[^0-9]", "");
String spec = s.replaceAll("[a-zA-Z0-9]", "");

15. Reverse each word in a string.

Solution:

String[] words = s.split(" ");
String res = "";
for(String w : words) res += new StringBuilder(w).reverse() + " ";

16. Count the occurrence of each character in a string.

Solution:

Map<Character, Integer> map = new HashMap<>();
for(char c : s.toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);

17. Print the first non-repeating character in a string.

Solution:

for(char c : s.toCharArray()) if(s.indexOf(c) == s.lastIndexOf(c)) { System.out.println(c); break; }
