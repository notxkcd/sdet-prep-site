Questions with Answers

Beginner (Basic Strings & Numbers)

1. Reverse a string?

Solution:

String s = "Java";
String rev = new StringBuilder(s).reverse().toString();

2. Find the number of alphabets in a sentence?

Solution:

int count = s.replaceAll("[^a-zA-Z]", "").length();

3. Separate numbers only from a string (Input: “09/24/2015”)?

Solution:

String s = "09/24/2015";
String res = s.replaceAll("[^0-9]", "");

4. Write a Factorial program?

Solution:

int f=1; for(int i=1; i<=n; i++) f*=i;

5. Swap two variables without using a 3rd variable?

Solution:

a = a + b; b = a - b; a = a - b;

6. Star pattern program (Pyramid)?

Solution:

for (int i=0; i<n; i++) {
    for (int j=n-i; j>1; j--) System.out.print(" ");
    for (int j=0; j<=i; j++) System.out.print("* ");
    System.out.println();
}

7. Write a program for an ArrayList to add elements and remove the first one?

Solution:

List<String> list = new ArrayList<>();
list.add("First"); list.add("Second");
list.remove(0);

8. Write a program that generates an ArithmeticException (Divide by zero) and handles it?

Solution:

try {
    int res = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Cannot divide by zero");
}

Intermediate (Intermediate Logic & Collections)

1. Reverse each word in a string (Input: “Good Girl”)?

Solution:

String[] words = s.split(" ");
String res = "";
for(String w : words) res += new StringBuilder(w).reverse() + " ";

2. Remove duplicate words or characters from a string?

Solution:

String res = Arrays.stream(s.split(" ")).distinct().collect(Collectors.joining(" "));

3. Check if a string is a Palindrome?

Solution:

boolean isPal = s.equals(new StringBuilder(s).reverse().toString());

4. Find the second largest number in an array?

Solution:

Arrays.sort(arr);
int res = arr[arr.length - 2];

5. Print descending order of an array?

Solution:

Arrays.sort(arr);
for(int i=arr.length-1; i>=0; i--) System.out.println(arr[i]);

6. Sort an array in ascending order?

Solution:

Arrays.sort(arr);

7. Print non-repeating numbers in an array?

Solution:

Map<Integer, Integer> map = new HashMap<>();
for(int x : arr) map.put(x, map.getOrDefault(x, 0) + 1);
map.forEach((k, v) -> { if(v == 1) System.out.println(k); });

8. Write a program to loop through an ArrayList using four different methods?

Solution:

// 1. For loop, 2. Enhanced For, 3. Iterator, 4. forEach()
for(int i=0; i<list.size(); i++);
for(String s : list);
Iterator<String> it = list.iterator();
list.forEach(System.out::println);

9. Demonstrate the use of the finally keyword in a program?

Solution:

try { int x = 5/0; }
finally { System.out.println("Always runs"); }
