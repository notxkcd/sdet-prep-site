Questions with Answers

Beginner (Basics)

1. Write a program to reverse a string?

Solution:

String s = "Java";
String rev = new StringBuilder(s).reverse().toString();

2. Write a program to find even and odd numbers in a given array?

Solution:

for(int x : arr) if(x % 2 == 0) System.out.println("Even: " + x); else System.out.println("Odd: " + x);

3. Swap two numbers with and without using a third variable?

Solution:

  • With 3rd variable: int temp = a; a = b; b = temp;
  • Without 3rd variable: a = a + b; b = a - b; a = a - b;

Intermediate (Intermediate Logic)

1. Write a program to count the occurrences of a specific character (e.g., ‘a’) in a given string?

Solution:

String s = "java language";
long count = s.chars().filter(ch -> ch == 'a').count();

2. Write a program to count the number of words in a given sentence?

Solution:

String s = "Java is fun";
int words = s.trim().split("\\s+").length;

3. Swap two strings without using a temporary variable?

Solution:

a = a + b;
b = a.substring(0, a.length() - b.length());
a = a.substring(b.length());
