Questions with Answers

Beginner (Basics)

1. Reverse a string?

Solution:

String rev = new StringBuilder(s).reverse().toString();

2. Reverse an integer number?

Solution:

int rev = 0; while(n != 0) { rev = rev * 10 + n % 10; n /= 10; }

3. Count vowels in a string?

Solution:

long count = s.toLowerCase().chars().filter(c -> "aeiou".indexOf(c) != -1).count();

4. Print vowels from a string?

Solution:

for(char c : s.toCharArray()) if("aeiouAEIOU".indexOf(c) != -1) System.out.println(c);

5. Find the maximum and minimum numbers in an array?

Solution:

int max = arr[0], min = arr[0];
for(int x : arr) { if(x > max) max = x; if(x < min) min = x; }

6. Swap two numbers without using a third variable?

Solution:

a = a + b; b = a - b; a = a - b;

7. Find the count of letters in a string?

Solution:

int count = s.replaceAll("[^a-zA-Z]", "").length();

8. Replace ‘-’ with ‘/’ in a date string?

Solution:

String res = s.replace('-', '/');

9. How to get system date and time?

Solution:

System.out.println(java.time.LocalDateTime.now());

10. Convert a string to an integer?

Solution:

int n = Integer.parseInt(s);

11. Get all variables from an array using a loop?

Solution:

for(int x : arr) System.out.println(x);

Intermediate (Intermediate Logic)

1. Reverse a string word by word?

Solution:

String[] w = s.split(" ");
String res = "";
for(int i=w.length-1; i>=0; i--) res += w[i] + " ";

2. Count duplicate characters in a string?

Solution:

Map<Character, Integer> map = new HashMap<>();
for(char c : s.toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);
map.forEach((k, v) -> { if(v > 1) System.out.println(k); });

3. Find the frequency of characters in a string?

Solution:

Map<Character, Integer> map = new HashMap<>();
for(char c : s.toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);

4. Find duplicate words in a string?

Solution:

String[] words = s.split(" ");
Set<String> set = new HashSet<>();
for(String w : words) if(!set.add(w)) System.out.println(w);

5. Reverse two numbers without using a temporary variable?

Solution:

x = x + y; y = x - y; x = x - y;

6. Reverse two strings without using a temporary variable?

Solution:

a = a + b; b = a.substring(0, a.length()-b.length()); a = a.substring(b.length());

7. Find the second highest number in an array?

Solution:

Arrays.sort(arr);
int res = arr[arr.length - 2];

8. Find duplicate elements in an array?

Solution:

Set<Integer> set = new HashSet<>();
for(int x : arr) if(!set.add(x)) System.out.println(x);

9. Sort an array?

Solution:

Arrays.sort(arr);

10. Convert an array to a list?

Solution:

List<Integer> list = Arrays.asList(arr);

11. Retrieve key-value pairs from a HashMap?

Solution:

map.forEach((k, v) -> System.out.println(k + "=" + v));

12. Write a POJO class for Username and Password?

Solution:

class User {
    private String u, p;
    public String getU() { return u; } public void setU(String u) { this.u = u; }
    public String getP() { return p; } public void setP(String p) { this.p = p; }
}

3. Remove duplicates from a string without using collection concepts?

Solution:

String res = "";
for(int i=0; i<s.length(); i++) if(!res.contains(""+s.charAt(i))) res += s.charAt(i);

4. Anagram check?

Solution:

char[] c1 = s1.toCharArray(); char[] c2 = s2.toCharArray();
Arrays.sort(c1); Arrays.sort(c2);
boolean res = Arrays.equals(c1, c2);

5. Count characters, numbers, and special characters in a mixed string?

Solution:

int l=0, d=0, sp=0;
for(char c : s.toCharArray()) {
    if(Character.isLetter(c)) l++; else if(Character.isDigit(c)) d++; else sp++;
}

6. Find the 3rd maximum element in an array?

Solution:

Arrays.sort(arr); int res = arr[arr.length - 3];

7. Sum of two integer arrays?

Solution:

int[] sum = new int[a.length];
for(int i=0; i<a.length; i++) sum[i] = a[i] + b[i];

8. Find common duplicates between two arrays?

Solution:

Set<Integer> s1 = new HashSet<>(Arrays.asList(a));
for(int x : b) if(s1.contains(x)) System.out.println(x);
