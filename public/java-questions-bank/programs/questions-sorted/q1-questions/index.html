Questions - 2025 Interview questions

Beginner (Basic Logic & Loops)

  1. Swap two numbers using a temporary variable?
  2. Write a code for String reverse?
  3. Reverse a number in Java?
  4. Print “Infosys” but skip the letter “o”?
  5. How to replace a letter from a string?
  6. Replace vowels with * (Input: “chennai”)?
  7. Find the maximum and minimum values in an array?
  8. Find the smallest value in an array?
  9. Print all dividends of 8 between 1 and 100?
  10. Sum the integers found in a mixed string?
  11. Write a code for Palindrome?

Intermediate (Intermediate Strings, Arrays & Logical Reasoning)

  1. Swap two variables without using a 3rd variable?
  2. Fibonacci series code?
  3. Write a sorting program?
  4. Find the second maximum value in an array?
  5. Find the second largest number in an array?
  6. Find duplicate numbers in an array?
  7. Find the maximum salary of an individual in an array?
  8. Count the occurrence of a character in a string?
  9. Find the occurrence of a substring in a string?
  10. How to replace multiple letters from a string using the same replace method?
  11. Separate String and Integer from a mixed list or array?
  12. Reverse the words in a string (Input: “test program”)?
  13. Format a string (Input: “xperience”, Output: “xprinc**”)?
  14. Extract ABC and 123 from “AB12C3” and print “ABC123”?
  15. Input: Same, Output: Saammmeeee?

Advanced (Advanced Algorithms, Complex Manipulations & Optimization)

  1. Check if two strings are Anagram or not (e.g., “Bored” and “Robed”)?
  2. Reverse each word in a given string without changing the caps and small letters?
  3. Find character count and duplicate characters in a string array?
  4. Remove duplicates from a string and print unique values (Input: “giggling”)?
  5. Remove duplicates in a long list of integers/strings?
  6. Count words greater than 5 and reverse only those?
  7. Split letters and numbers from a string and print them separately (Input: “1am a C0dingF4n 0r Pr0gr4mm3r or S0ftw4r3 D3v3l0p3r”)?
  8. Print the frequency of integers and letters in a mixed string?
  9. Array rotational coding?
  10. Sum the numbers in a mixed array (e.g., from 1,2,3,a,b,c sum 1,2,3)?
  11. Find the occurrence of a specific number in a long sequence?
  12. Transpose a 2D array?
  13. Declare a 2D array and perform operations?
  14. Input: int [] = [1,0,0,2,0,0,0,3], Output: [1,2,3,0,0,0]?
  15. Input: a (1,2,3,a,b,c), Task: Remove (a b c) and sum (1 2 3)?
