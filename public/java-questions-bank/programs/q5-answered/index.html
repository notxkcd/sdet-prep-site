Beginner (Basics)

1. Reverse a string.

Solution:

String rev = new StringBuilder(s).reverse().toString();

2. Reverse an integer number.

Solution:

int rev = 0; while(n != 0) { rev = rev * 10 + n % 10; n /= 10; }

3. Count the number of letters in a given string (e.g., “Hello” -> 5).

Solution:

int count = s.length();

4. Factorial program.

Solution:

int f=1; for(int i=1; i<=n; i++) f*=i;

5. Swap two variables without using a 3rd variable.

Solution:

a = a + b; b = a - b; a = a - b;

6. Find the minimum and maximum value in a collection of numbers.

Solution:

int min = Collections.min(list);
int max = Collections.max(list);

7. Check if a number is a Palindrome.

Solution:

// Convert to string and check if equals reverse.

8. Check if a string is a Palindrome.

Solution:

boolean isPal = s.equals(new StringBuilder(s).reverse().toString());

9. Check if a number is a Prime number.

Solution:

boolean isPrime = IntStream.rangeClosed(2, (int)Math.sqrt(n)).noneMatch(i -> n % i == 0);

10. Write code to read data from a Property file.

Solution:

Properties p = new Properties();
p.load(new FileInputStream("file.properties"));
String val = p.getProperty("key");

Intermediate (Intermediate Logic)

11. Count vowels and non-vowels in a string.

Solution:

int v=0, c=0;
for(char ch : s.toLowerCase().toCharArray()) {
    if("aeiou".indexOf(ch) != -1) v++;
    else if(ch >= 'a' && ch <= 'z') c++;
}

12. Count the frequency of a letter in a string.

Solution:

long freq = s.chars().filter(ch -> ch == 'a').count();

13. Fibonacci series.

Solution:

int a=0, b=1; for(int i=0; i<n; i++) { System.out.print(a+" "); int sum=a+b; a=b; b=sum; }

14. Check if a number is an Armstrong number.

Solution:

int sum=0, temp=n; while(temp>0){ int r=temp%10; sum+=(r*r*r); temp/=10; }

15. Sort an ArrayList in ascending order.

Solution:

Collections.sort(list);

16. Separate numbers and alphabets from a mixed string.

Solution:

String alph = s.replaceAll("[0-9]", "");
String nums = s.replaceAll("[^0-9]", "");

17. Count digits of ‘a’ in a sentence.

Solution:

long count = s.chars().filter(ch -> ch == 'a').count();

18. How to replace ‘.’ with a space in an email only between names (not after @).

Solution:

String[] parts = email.split("@");
parts[0] = parts[0].replace(".", " ");
String res = parts[0] + "@" + parts[1];

Advanced (Algorithms & Complex Challenges)

19. Reverse each word in a string but keep the word position.

Solution:

String res = Arrays.stream(s.split(" ")).map(w -> new StringBuilder(w).reverse().toString()).collect(Collectors.joining(" "));

20. Reverse a string (Input: “Deepak Kumar”, Output: “kapeed ramuk”).

Solution:

String res = new StringBuilder(s.toLowerCase()).reverse().toString();

21. Count the occurrence of each character in a string.

Solution:

Map<Character, Long> freq = s.chars().mapToObj(c -> (char)c).collect(Collectors.groupingBy(Function.identity(), Collectors.counting()));

22. Remove all special characters from a string.

Solution:

String res = s.replaceAll("[^a-zA-Z0-9]", "");

23. Remove duplicates from a string without using Set.

Solution:

String res = ""; for(char c : s.toCharArray()) if(res.indexOf(c) == -1) res += c;

24. Input: String name = a2b3c2, Output: aabbbcc.

Solution:

for(int i=0; i<s.length(); i+=2) {
    char c = s.charAt(i);
    int count = s.charAt(i+1) - '0';
    for(int j=0; j<count; j++) System.out.print(c);
}

25. Sort a 2D array.

Solution:

Arrays.sort(arr, (a, b) -> Integer.compare(a[0], b[0]));

26. Can you execute a method without writing a main method?

Answer: Yes, using a Static Block (in older Java versions) or using Testing Frameworks (JUnit/TestNG).

27. Logic to count duplicates in “babcadaefhef”.

Solution:

Map<Character, Integer> map = new HashMap<>();
for(char c : "babcadaefhef".toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);
