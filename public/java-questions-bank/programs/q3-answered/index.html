Beginner (Basic Strings & Numbers)

1. Reverse a string.

Solution:

String rev = new StringBuilder(s).reverse().toString();

2. Find the number of alphabets in a sentence.

Solution:

int count = s.replaceAll("[^a-zA-Z]", "").length();

3. Separate numbers only from a string (Input: “09/24/2015”).

Solution:

String nums = s.replaceAll("[^0-9]", "");

4. Write a Factorial program.

Solution:

int f=1; for(int i=1; i<=n; i++) f*=i;

5. Swap two variables without using a 3rd variable.

Solution:

a = a + b; b = a - b; a = a - b;

6. Star pattern program (Pyramid).

Solution:

for (int i=0; i<n; i++) {
    for (int j=n-i; j>1; j--) System.out.print(" ");
    for (int j=0; j<=i; j++) System.out.print("* ");
    System.out.println();
}

Intermediate (Intermediate Logic & Collections)

7. Reverse each word in a string (Input: “Good Girl”).

Solution:

String[] words = s.split(" ");
String res = "";
for(String w : words) res += new StringBuilder(w).reverse() + " ";

8. Remove duplicate words or characters from a string.

Solution:

String res = Arrays.stream(s.split(" ")).distinct().collect(Collectors.joining(" "));

9. Check if a string is a Palindrome.

Solution:

boolean isPal = s.equals(new StringBuilder(s).reverse().toString());

10. Find the second largest number in an array.

Solution:

Arrays.sort(arr);
int secondMax = arr[arr.length - 2];
