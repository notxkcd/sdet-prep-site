Final Verdict

Hireability Score: 6.5 / 10

Summary: You are a hireable candidate for Junior to Early-Mid level roles. You have the right keywords and the foundational experience. However, you lack depth in specialized areas (CI/CD, Framework Architecture) and have a significant career gap that needs a confident explanation.

What Will Reject You Immediately?

  • Fumbling the “Framework” question: If you can’t draw your framework structure on a whiteboard or explain why you used POM, you are out.
  • Inability to code simple logic: Failing a basic Java string manipulation or loop question.
  • Vague Gap Explanation: “I was just looking for a job” for 2 years is a red flag. Have a better story.

What Will Impress a Senior SDET?

  • Honesty about limitations: “I haven’t set up the Jenkins pipeline from scratch, but I know how to debug console logs when it fails.”
  • Debugging skills: Explaining how you debug a failure (Check logs -> Check screenshot -> Reproduce locally) shows maturity.
  • Code Quality: Writing clean, readable code in the interview (proper naming conventions) matters more than getting the syntax 100% right.
