Beginner (Basics)

Write a program to reverse a string.

s = "hello"
print(s[::-1]) # "olleh"

Write a program to find even and odd numbers in a given list.

lst = [1, 2, 3, 4, 5]
evens = [x for x in lst if x % 2 == 0]
odds = [x for x in lst if x % 2 != 0]
print("Evens:", evens) # [2, 4]
print("Odds:", odds) # [1, 3, 5]

Swap two numbers with and without using a third variable.

a, b = 1, 2
# With temp
temp = a; a = b; b = temp
print(a, b) # 2 1
# Without temp
a, b = b, a
print(a, b) # 1 2
