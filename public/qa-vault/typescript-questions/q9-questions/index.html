Answers

Beginner (Basics)

Write a program to reverse a string.

const str = "hello";
console.log(str.split("").reverse().join("")); // "olleh"

Write a program to find even and odd numbers in a given array.

const arr = [1, 2, 3, 4, 5];
const evens = arr.filter(n => n % 2 === 0);
const odds = arr.filter(n => n % 2 !== 0);
console.log("Evens:", evens); // [2, 4]
console.log("Odds:", odds); // [1, 3, 5]

Swap two numbers with and without using a third variable.

let a = 1, b = 2;
// With temp
let temp = a; a = b; b = temp;
console.log(a, b); // 2 1
// Without temp
[a, b] = [b, a];
console.log(a, b); // 1 2

Swap two strings without using a temporary variable.

[s1, s2] = [s2, s1];
