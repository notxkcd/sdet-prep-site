Questions with Answers

Beginner (Basics)

1. Explain the OOPS concepts?

Answer:

  • Encapsulation: Hiding internal data via private access.
  • Inheritance: Code reuse by having one class extend another.
  • Polymorphism: One action, multiple behaviors (Overloading/Overriding).
  • Abstraction: Showing essential features and hiding complexity.

2. What is an abstract class in Java?

Answer: A class that cannot be instantiated and is used as a template for other classes. It can have both abstract and implemented methods.

3. What is a constant variable in Java?

Answer: A variable whose value cannot be modified after it is assigned, declared using the final keyword.

Intermediate (Detailed Comparisons)

1. What are the differences and similarities between a class and an interface?

Answer:

  • Differences: A class can have state (instance variables), while an interface cannot. A class is extended, while an interface is implemented.
  • Similarities: Both define types and serve as blueprints for behavior.

2. Constructor: Explain default constructor execution and its usage in your project?

Answer: A default constructor is automatically provided by the compiler if none is defined. It initializes object fields with default values. Used in projects to instantiate page objects.

3. What are the different keywords (methods) available under List and Set?

Answer:

  • List: add(), get(index), remove(), size(), set().
  • Set: add(), remove(), contains(), isEmpty(), size(). (Note: Set does not have index-based get().)
