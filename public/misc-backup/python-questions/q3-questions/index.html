Write a Factorial program.

import math
print(math.factorial(5)) # 120
# Or recursive:
def factorial(n):
    return 1 if n <= 1 else n * factorial(n-1)
print(factorial(5))

Write a program to loop through a list using four different methods.

lst = [1, 2, 3]

# 1. For loop
for x in lst: print(x)

# 2. While loop
i = 0
while i < len(lst):
    print(lst[i])
    i += 1

# 3. Enumerate
for i, x in enumerate(lst): print(x)

# 4. List comprehension (side effect)
[print(x) for x in lst]

Find the occurrence of every character in “Welcome to Wipro”.

counts = {c: s.count(c) for c in set(s) if c.strip()}

Print all possible combinations of a string (Input: “abc”).

from itertools import permutations
s = "abc"
perms = [''.join(p) for p in permutations(s)]
print(perms) # ['abc', 'acb', 'bac', 'bca', 'cab', 'cba']

Demonstrate raising an exception in a function.

def divide(a, b):
    if b == 0:
        raise ValueError("Cannot divide by zero")
    return a / b

try:
    divide(10, 0)
except ValueError as e:
    print(e)
