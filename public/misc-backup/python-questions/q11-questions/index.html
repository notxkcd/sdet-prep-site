  • Write a program to convert a Dictionary to a List (of keys, values, or items).

  • Write a program using a Dictionary to find the number of occurrences of each character in a string.

Answers

Intermediate

Write a program to convert a Dictionary to a List (of keys, values, or items).

d = {'a': 1, 'b': 2}
print(list(d.keys()))   # ['a', 'b']
print(list(d.values())) # [1, 2]
print(list(d.items()))  # [('a', 1), ('b', 2)]

Advanced

Write a program using a Dictionary to find the number of occurrences of each character in a string.

s = "hello world"
counts = {}
for char in s:
    counts[char] = counts.get(char, 0) + 1
print(counts)
