Answers

Beginner (Basics)

Write a program to reverse a string (Generic).

print(s[::-1])

Reverse a string using a loop and using an inbuilt function (slicing).

s = "hello"
# Loop
rev = ""
for char in s:
    rev = char + rev
print(rev)
# Inbuilt (slicing)
print(s[::-1])

Advanced (Advanced Algorithms & Logic)

Find duplicate characters and unique characters in a string (Input: weqjhjkAJKDbdnmbcnm).

s = "weqjhjkAJKDbdnmbcnm"
counts = {c: s.count(c) for c in set(s)}
duplicates = [c for c, count in counts.items() if count > 1]
unique = [c for c, count in counts.items() if count == 1]
print("Duplicates:", duplicates)
print("Unique:", unique)
