🚀 1. The Only Mental Model You Need

A regex in Java is just:

Pattern  +  Matcher  +  Input String

Java’s regex is basically PCRE-lite.

Workflow:

Pattern p = Pattern.compile("regex");
Matcher m = p.matcher("input");
m.find();    // search
m.matches(); // full match

🎯 2. Core Syntax You Must Remember (Minimal, Essential)

Literals

a    → literal 'a'
\.   → dot literal

Character classes

[abc]    → a or b or c
[^abc]   → NOT a/b/c
[a-zA-Z] → ranges

Shorthand:

\d  → digits
\D  → non-digits
\w  → letters + digits + _
\W  → not \w
\s  → whitespace
\S  → not whitespace

Quantifiers

*  → 0+
+  → 1+
?  → 0 or 1
{n}       → exactly n
{n,}      → n or more
{n,m}     → between n and m

Greedy vs Lazy:

.*      → greedy
.*?     → lazy

Anchors

^   → start of string
$   → end of string
\b  → word boundary
\B  → not boundary

Groups

(abc)       → capturing group
(?:abc)     → non-capturing
(?=abc)     → lookahead
(?!abc)     → negative lookahead

Java does NOT have lookbehind until Java 9+ (now it does):

(?<=abc)  → lookbehind
(?<!abc)  → negative lookbehind

⚙️ 3. Java-Specific Gotchas

Java needs double escaping, because strings process escapes before regex sees them.

Examples:

"\\."    // literal dot
