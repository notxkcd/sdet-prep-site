Style Comparison

1. Current Default Style

This is what you have right now. Clean and simple.

public static void main(String[] args) {
    // Just code, nothing else
    System.out.println("Hello World");
}
The default blockquote is simple indentation with a gray border line. It gets the job done without shouting.

2. Proposed "Org-Mode" Style

This adds the 'geeky' flavor symbols you asked about.

public static void main(String[] args) {
    // Notice the label above
    System.out.println("Hello World");
}
This blockquote has a tinted background, a green accent border, and the large quote mark symbol to separate it visually from normal text.
