Beginner (Basics & Definitions)

1. What are the data types in Java?

Answer: Primitives (e.g., int, char, boolean) and Non-Primitives (e.g., String, Array, Classes).

2. Explain the super and this keywords.

Answer: this refers to the current class instance; super refers to the immediate parent class instance.

3. What is the new keyword in Java?

Answer: Used to create a new object and allocate memory on the heap.

4. What is a Wrapper class?

Answer: Classes that convert primitives into objects (e.g., Integer for int).

5. What are the different types of access modifiers?

Answer:

  • public: Access from anywhere.
  • private: Access only within the class.
  • protected: Same package + subclasses.
  • default: Same package only.

6. What is the purpose of the static keyword in the main method?

Answer: It allows the JVM to call the main method without creating an instance of the class.

7. What is the java.awt package?

Answer: A legacy package for creating Graphical User Interfaces (GUI) and graphics.

8. What are the uses of the JDK?

Answer: The Java Development Kit (JDK) provides the tools (compiler, debugger) needed to develop and run Java programs.

9. Difference between a .java file and a .class file.

Answer: .java contains source code; .class contains compiled bytecode for the JVM.

10. Difference between while and do-while loops.

Answer: while checks the condition first; do-while executes once before checking.

11. What is a NullPointerException?

Answer: Occurs when trying to access a member of an object reference that points to null.

12. What is an ArithmeticException?

Answer: Thrown when an exceptional arithmetic condition occurs, like division by zero.

Intermediate (Differences & Practical Logic)

13. Difference between this() and super().

Answer: this() calls another constructor in the same class; super() calls a parent class constructor.

14. Difference between Abstraction and Encapsulation.

Answer: Abstraction hides implementation (focus on “what”); Encapsulation hides data (focus on “how” to protect state).

15. Difference between an Abstract Class and an Interface.

Answer: Abstract classes can have state and shared code; Interfaces are contracts (behavior blueprints).

16. Difference between a Method and a Constructor.

Answer: A method performs an action and has a return type; a constructor initializes an object and has no return type.

17. What is a Constructor?

Answer: A special method used to initialize objects when they are created.

18. Difference between final, finally, and finalize.

Answer: final is a keyword (restriction); finally is a block (cleanup); finalize is a method (GC cleanup).

19. Difference between StringBuffer and StringBuilder.

Answer: StringBuffer is synchronized (thread-safe); StringBuilder is faster (not thread-safe).

20. Difference between String str = "abc" and String str = new String("abc").

Answer: The first uses the String Pool; the second always creates a new object on the heap.

21. What is the difference between List and Map?

Answer: List is a sequence of values; Map is a collection of key-value pairs.

22. What is Set?

Answer: A collection that stores unique elements and prevents duplicates.

23. Difference between ArrayList and LinkedList.

Answer: ArrayList is better for retrieval (index-based); LinkedList is better for manipulation (insertion/deletion).

24. Difference between HashMap and HashTable.

Answer: HashMap is faster and allows one null key; HashTable is synchronized and legacy.

25. What are checked and unchecked exceptions?

Answer: Checked are caught at compile-time; Unchecked are caught at runtime (usually logic errors).

26. Scope and differences between default, protected, and private.

Answer: Private is class-only; Default is package-only; Protected is package + child classes.

27. What is the scope of a private method?

Answer: Only visible within the class where it is declared.

28. How do you find the square root of a number in Java using a direct method?

Answer: Using Math.sqrt(number).

Advanced (Internal Workings & Project Integration)

29. What are the OOPS concepts and how are they used in your project?

Answer: Used to structure the framework (Inheritance for base setup, Encapsulation for POM, Polymorphism for driver handling).

30. What are Copy Constructors and Constructor Chaining?

Answer: A copy constructor initializes an object from another of the same class. Chaining is calling constructors sequentially using this() or super().

31. What is the return type of a constructor?

Answer: It has no return type, not even void.

32. Can we use static methods in a constructor?

Answer: Yes, but they should not depend on the object being initialized.

33. What is a Static block in Java?

Answer: A block of code that runs once when the class is first loaded by the JVM.

34. Can we override static methods?

Answer: No, they are “hidden” rather than overridden (Method Hiding).

35. What happens if the static keyword is missing from main?

Answer: The JVM will fail to run the class as a standalone application.

36. Can the order of public static void be changed in the main method?

Answer: You can swap public and static, but void must come immediately before main.

37. Can we write a try-catch block without the catch block?

Answer: Only if followed by a finally block.

38. What is a functional interface?

Answer: An interface with exactly one abstract method (e.g., Predicate, Runnable).

39. Difference between static and abstract classes.

Answer: There is no “static class” at the top level; nested classes can be static. Abstract classes cannot be instantiated.

40. How do you use Collections in your framework?

Answer: To store WebElements (List<WebElement>), test data (Map<String, String>), or unique results (Set).
