Beginner (Basics)

1. Explain the OOPS concepts.

Answer:

  • Encapsulation: Bundling data and code together.
  • Inheritance: Acquiring features from a parent class.
  • Polymorphism: One action performing in different ways.
  • Abstraction: Hiding internal details and showing functionality.

2. What is an abstract class in Java?

Answer: A class that cannot be instantiated and can contain both abstract methods (without body) and concrete methods (with body).

3. What is a constant variable in Java?

Answer: A variable whose value cannot be modified after assignment, declared with the final keyword.

Intermediate (Detailed Comparisons)

4. What are the differences and similarities between a class and an interface?

Answer:

  • Differences: A class can have state (instance variables), while interfaces cannot. A class is extended, while an interface is implemented.
  • Similarities: Both can have methods (interfaces through default since Java 8) and serve as blueprints.

5. Constructor: Explain default constructor execution and its usage in your project.

Answer: A default constructor is automatically provided by the compiler if none is defined. It initializes objects with default values. In projects, it’s used to instantiate page objects or base classes without specific initial data.

6. What are the different keywords (methods) available under List and Set?

Answer:

  • List: add(), get(index), remove(), size(), set(), indexOf().
  • Set: add(), remove(), contains(), isEmpty(), size(), clear(). (Note: Set does not have get(index).)
