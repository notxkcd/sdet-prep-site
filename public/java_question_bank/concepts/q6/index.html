Beginner (Basics)

1. What is the difference between a class and an object?

Answer: A class is a blueprint or template; an object is a physical instance of that blueprint.

2. What are Primitives and Non-Primitive data types?

Answer: Primitives (e.g., int, boolean) store simple values; Non-Primitives (e.g., String, Array) are complex objects and store references.

3. Is String a primitive or non-primitive data type?

Answer: Non-primitive. It is a class in Java.

4. What are the different types of variables in Java (Static, Instance, Local)?

Answer:

  • Static: Shared by all objects of the class.
  • Instance: Specific to each object instance.
  • Local: Declared inside a method or block.

5. What is an Interface?

Answer: A blueprint of behavior that a class must implement (a contract).

6. What is the keyword used to implement an interface in a child class?

Answer: implements.

7. What are Wrapper classes and why are they used?

Answer: Classes like Integer and Double that wrap primitives so they can be used in collections.

8. What is the break keyword and why is it used?

Answer: Used to exit a loop or switch block immediately.

9. What is the output of System.out.println(2 + 3 + "HELLO")?

Answer: 5HELLO (Arithmetic addition happens before string concatenation).

10. What is the “super head” of all classes?

Answer: The Object class in the java.lang package.

Intermediate (Implementation & Logical Differences)

11. Explain OOPS concepts in detail.

Answer: Encapsulation (data hiding), Inheritance (code reuse), Polymorphism (multiple forms), Abstraction (essential features only).

12. Difference between Method Overloading and Method Overriding.

Answer: Overloading happens in the same class (different parameters); Overriding happens in parent/child classes (same parameters).

13. Explain Inheritance and the types of inheritance.

Answer: Mechanism where one class inherits from another. Types: Single, Multilevel, Hierarchical.

14. Difference between Abstraction and Encapsulation.

Answer: Abstraction focuses on “what” an object does; Encapsulation focuses on “how” to hide internal data.

15. What is the difference between this and super keywords?

Answer: this refers to the current object; super refers to the parent object.

16. What is a Constructor? Why do we need one in a project?

Answer: A special method to initialize objects. Required to set initial state or inject dependencies (like WebDriver).

17. Access Modifiers: Scope and differences.

Answer: Private (class), Default (package), Protected (package+child), Public (anywhere).

18. What is the scope of a private method?

Answer: Only accessible within the same class.

19. How do you use a private variable in another class?

Answer: Using public Getter and Setter methods.

20. String is immutable. How do you change or update a string value?

Answer: By using StringBuilder or StringBuffer, or by re-assigning the reference to a new string object.

21. Difference between == and .equals().

Answer: == compares memory addresses; .equals() compares content.

22. Difference between StringBuffer and StringBuilder.

Answer: StringBuffer is synchronized (thread-safe); StringBuilder is faster but not thread-safe.

23. What is the difference between List, Set, and Map?

Answer: List allows duplicates and order; Set prohibits duplicates; Map stores key-value pairs.

24. Difference between Array and ArrayList.

Answer: Array is fixed-size and primitive-friendly; ArrayList is dynamic-sized and object-only.

25. What are Collections in Java?

Answer: A framework providing interfaces and classes to store and manipulate groups of objects.

26. What is a HashMap?

Answer: A collection that uses hashing to store data in key-value pairs for fast access.

27. Explain Exception and its types.

Answer: Events that disrupt program execution. Types: Checked (compile-time) and Unchecked (runtime).

28. Difference between final, finally, and finalize.

Answer: final is a restriction; finally is a cleanup block; finalize is a pre-GC cleanup method.

29. Can we change a variable once it’s declared final?

Answer: No, it becomes a constant.

Advanced (Deep Dives & Scenario Based)

30. Explain Polymorphism (Static vs. Dynamic).

Answer: Static (Overloading) is resolved at compile-time; Dynamic (Overriding) is resolved at run-time based on the object instance.

31. Why is Multiple Inheritance not supported in Java?

Answer: To avoid ambiguity (Diamond Problem) where multiple parents have conflicting implementations of the same method.

32. Can we have multiple constructors in the same class?

Answer: Yes, this is known as Constructor Overloading.

33. Can an abstract method be final?

Answer: No, because abstract methods must be overridden, and final methods cannot be overridden.

34. Can an abstract class contain a final method?

Answer: Yes, it can contain implemented methods that child classes are not allowed to change.

35. What is a Static block?

Answer: A block of code that executes when the class is first loaded by the JVM, before the main method or any object creation.

36. What is a Functional Interface and a Lambda Expression?

Answer: A Functional Interface has one abstract method. Lambda expressions provide a concise implementation for these interfaces.

37. What is Serialization in Java?

Answer: Converting an object’s state into a byte stream for storage or transmission.

38. Can a final method be overridden?

Answer: No.

39. How do you troubleshoot an exception?

Answer: By reading the stack trace, using debugging tools, and verifying the logic at the line number provided.

40. Can we store objects in a HashMap and how do we retrieve them?

Answer: Yes, as either keys or values. Retrieve them using map.get(key).

41. Does Map allow null values?

Answer: HashMap allows one null key and multiple null values. HashTable does not allow any.

42. How do you initialize a HashMap?

Answer: Map<String, String> map = new HashMap<>();.
