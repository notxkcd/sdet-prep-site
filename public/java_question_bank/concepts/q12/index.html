Beginner

1. Explain Maven and its purpose.

Answer: Maven is a build automation and project management tool. Its primary purpose is to manage project dependencies, automate the build process (compiling, testing, packaging), and provide a uniform project structure.

2. Why are you using Maven in your project?

Answer: To simplify dependency management (no need to manually download JARs), automate builds, and ensure consistent environments across the team.

Intermediate

3. What is the use of Maven and what are its goals?

Answer: Maven is used to manage the full lifecycle of a project. Its goals (phases) define specific tasks like cleaning, compiling, and testing.

4. What does the pom.xml file in Maven do?

Answer: It is the heart of a Maven project. It contains configurations like dependencies, plugins, project version, and repository details.

5. List common Maven goals.

Answer:

  • clean: Deletes the target directory.
  • compile: Compiles the source code.
  • test: Runs unit tests.
  • package: Creates a JAR or WAR file.
  • install: Copies the package to the local repository.

6. What code do you use for Maven in your project?

Answer: This usually refers to the XML tags in pom.xml (like <dependency>, <plugin>, <groupId>, <artifactId>, <version>).
