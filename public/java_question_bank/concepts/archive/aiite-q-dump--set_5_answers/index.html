Beginner (Basics)

Access Modifiers?

  • public: Open to all.
  • protected: Package + Subclasses.
  • default: Package only.
  • private: Class only.

Abstraction vs Encapsulation?

  • Abstraction: Hiding the “how” (using abstract or interface).
  • Encapsulation: Protecting data (using private fields + public getters/setters).

Intermediate (Practical Implementation & Differences)

final vs finally vs finalize?

  • final: Constant/Restriction.
  • finally: Code block that always runs (for cleanup).
  • finalize: Method for garbage collection cleanup.

Literal vs Non-Literal String?

  • String s = "Java" (Literal): Stored in String Pool.
  • String s = new String("Java") (Non-Literal): Stored on Heap.

Advanced (Internal Mechanics & Scenarios)

What is Garbage Collection?

The process of automatically deleting objects that are no longer used by the program to free up memory. JVM calls System.gc() (or automatically) to trigger it.
