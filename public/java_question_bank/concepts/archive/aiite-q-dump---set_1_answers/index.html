Java Concepts

Beginner (Basics & Definitions)

What are access modifiers?

Keywords that control visibility:

  • public: Access from anywhere.
  • private: Access only within the same class.
  • protected: Access within same package and subclasses.
  • default: Access only within the same package.

Difference between while and do-while?

  • while: Checks condition before running code.
  • do-while: Runs code once before checking the condition.

Intermediate (Differences & Practical Logic)

Difference between this and super?

  • this() calls the constructor of the current class.
  • super() calls the constructor of the parent class.

Difference between List and Map?

  • List: Stores a sequence of elements (e.g., Apple, Banana).
  • Map: Stores data in pairs (e.g., 1 -> Apple, 2 -> Banana).

What are checked and unchecked exceptions?

  • Checked: Compile-time (e.g., FileNotFoundException). Java forces you to handle it.
  • Unchecked: Runtime (e.g., ArrayIndexOutOfBoundsException). Caused by programming errors.

Advanced (Internal Workings & Project Integration)

What is Constructor Chaining?

When one constructor calls another constructor in the same class (using this()) or parent class (using super()).

Can we override static methods?

No. Static methods are bound to the class at compile time, not to the object at runtime. This is called “Method Hiding.”

What is a functional interface?

An interface with only one abstract method. It is used to simplify code using Lambda expressions (Java 8+).
