Java Concepts

Beginner (Basics)

Difference between a class and an object?

A class is the blueprint; an object is the actual building.

What are Wrapper classes?

Classes that let you use primitives as objects (e.g., int -> Integer). This is needed for Collections like ArrayList.

What is the break keyword?

It is used to exit a loop or a switch statement immediately.

Intermediate (Implementation & Differences)

Difference between Method Overloading and Method Overriding?

  • Overloading: Same name, different parameters (Same class). Compile-time.
  • Overriding: Same name, same parameters (Parent & Child). Run-time.

Difference between List, Set, and Map?

  • List: Allows duplicates, keeps order.
  • Set: No duplicates, no order.
  • Map: Key-Value pairs, unique keys.

Difference between final, finally, and finalize?

  • final: Constant/Restriction.
  • finally: Code block that always runs.
  • finalize: Cleanup method for Garbage Collector.

Advanced (Deep Dives & Scenario Based)

Why is Multiple Inheritance not supported in Java?

To avoid the “Diamond Problem” where a child doesn’t know which parent’s method to use if both have the same one. Java uses Interfaces to solve this.

What is a Functional Interface?

An interface with one abstract method (e.g., Runnable). It allows using Lambda expressions for cleaner code.

What is Serialization?

The process of converting an object into a byte stream so it can be stored or sent over a network.
