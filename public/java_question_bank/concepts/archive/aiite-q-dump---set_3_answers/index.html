Beginner (Basics)

Difference between Local and Global variables?

  • Local: Declared inside a method. Only visible there.
  • Global (Instance): Declared outside methods. Visible to all methods in the class.

Syntax for if-else?

if (condition) {
    // code
} else {
    // code
}

Intermediate (Conceptual Implementation)

Abstract Class vs Interface?

  • Abstract Class: Can have shared code (implemented methods).
  • Interface: A pure contract (all methods abstract until Java 8).

Constructor vs Method?

  • Constructor: Initializes an object. Same name as class. No return type.
  • Method: Performs an action. Different name. Must have a return type.

Advanced (Internal & Project Specific)

How to throw a custom exception?

class MyException extends Exception {
    public MyException(String msg) { super(msg); }
}

// In code:
if (error) throw new MyException("Custom Error");

Inheritance Implementation:

In a framework, we use extends to inherit properties from a BasePage or BaseTest class to reuse driver initialization and common utilities.
