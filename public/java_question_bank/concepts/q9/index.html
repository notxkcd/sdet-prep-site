Beginner (Basics)

1. Provide examples of Abstraction, Interface, and Encapsulation.

Answer:

  • Abstraction: A BasePage defining click() without defining the logic.
  • Interface: WebDriver defining browser actions.
  • Encapsulation: Private locators accessed via public login() method.

2. Explain Inheritance and its types.

Answer: Sharing code between parent and child classes. Types: Single, Multilevel, Hierarchical.

3. What are the Access Modifiers and their scopes?

Answer: public (anywhere), private (same class), protected (package+child), default (same package).

Intermediate (Practical Implementation & Differences)

4. How do you use Abstract classes in your project?

Answer: To create a generic parent class (like BasePage) that contains shared properties like driver and common utility methods.

5. How do you use Interfaces in your project?

Answer: To define common behavior for unrelated classes or to use predefined Selenium interfaces like WebDriver.

6. Difference between List and Set.

Answer: List is an ordered collection allowing duplicates; Set is an unordered collection of unique elements.

7. Explain the difference between final, finally, and finalize.

Answer: final is a keyword for constants; finally is a block for cleanup; finalize is a method for GC.

8. What is the difference between Literal and Non-Literal Strings?

Answer: Literal ("abc") uses String Pool for memory efficiency; Non-literal (new String("abc")) always creates a new heap object.

Advanced (Internal Mechanics & Scenarios)

9. Explain the Garbage Collector in Java.

Answer: A background process that monitors heap memory and automatically deletes unreachable objects to free space.

10. Where have you implemented Method Overloading and Method Overriding in your project?

Answer:

  • Overloading: Utility methods like waitAndClick(locator) and waitAndClick(locator, timeout).
  • Overriding: Custom methods in specific page classes that redefine behavior from BasePage.
