Beginner (Fundamentals)

1. What is abstraction?

Answer: Abstraction is hiding the complex “how” and showing only the essential “what.” It simplifies interaction by focusing on functionality rather than implementation.

2. What is the static keyword?

Answer: It means the member belongs to the class, not to any specific object. It is shared across all instances.

3. What is the use of the super keyword?

Answer: To refer to the immediate parent class instance or to call the parent’s constructor.

4. Explain the this keyword.

Answer: Refers to the current class instance, often used to resolve ambiguity between instance variables and parameters.

5. Member access modifiers (Public, Private, Protected, Default).

Answer:

  • public: Access from anywhere.
  • private: Access only within the class.
  • protected: Same package + subclasses.
  • default: Same package only.

6. What is a HashMap?

Answer: A collection that stores data in Key-Value pairs for fast retrieval based on a unique key.

7. What is a NullPointerException and how do you avoid it?

Answer: Occurs when accessing a member of a null object. Avoid it with null checks (if (obj != null)) or using Optional.

Intermediate (Implementation & Logical Differences)

8. Difference between final and finally.

Answer: final is a keyword for restrictions (constants); finally is a block that always runs after try-catch for cleanup.

9. Explain static and final keywords.

Answer: static makes a member class-level; final makes it unchangeable.

10. Difference between an Abstract Class and an Interface.

Answer: Abstract classes can have state and implemented methods; Interfaces are contracts (purely abstract until Java 8).

11. Why use an Interface instead of an Abstract Class?

Answer: When you need to define a contract for unrelated classes or when multiple inheritance of behavior is needed.

12. Inheritance: How is it used in your project?

Answer: To reuse common automation code (like a BasePage class) across specific page objects.

13. Where have you applied overloading and overriding methods in your project?

Answer: Overloading for generic clicks (with or without timeout); Overriding for custom element interactions in specific pages.

14. Difference between List and Set.

Answer: List is ordered and allows duplicates; Set is unordered and disallows duplicates.

15. Difference between Array and ArrayList.

Answer: Array has fixed size and holds primitives/objects; ArrayList has dynamic size and holds only objects.

16. Can we use multiple catch blocks in Java?

Answer: Yes, to handle different types of exceptions separately.

17. Difference between throw and throws.

Answer: throw is used to throw an exception; throws is used to declare that a method might throw one.

18. How do you handle exceptions like ArithmeticException?

Answer: By wrapping the risky code (like division) in a try-catch block.

19. How to sort a collection using Collections.sort()?

Answer: Pass the List to the method: Collections.sort(myList);. Objects must implement Comparable.

Advanced (Deep Dives & Scenarios)

20. What are the OOPS concepts in Java and how are they implemented in your Selenium project?

Answer:

  • Encapsulation: Locators hidden in POM.
  • Inheritance: Base classes for setup.
  • Polymorphism: WebDriver interface.
  • Abstraction: WebElement interface.

21. How can you access all methods of Class A in Class B?

Answer: Through Inheritance (B extends A) or Composition (B has an instance of A).

22. How do you use constructors in Selenium/Java?

Answer: To initialize the WebDriver instance when creating a Page Object.

23. What is a functional interface?

Answer: An interface with exactly one abstract method (e.g., Runnable).

24. What is a lambda expression?

Answer: A concise way to implement a functional interface.

25. Where have you used the Collections framework in your automation project?

Answer: List<WebElement> for finding multiple elements; Map for storing test data or configuration.

26. Explain the Java Collections framework and the data structures it provides.

Answer: A framework providing interfaces (List, Set, Map) and classes (ArrayList, HashSet, HashMap) to manage groups of data.

27. If you use 3 catch blocks, how will you declare their hierarchy?

Answer: Subclasses must come before superclasses (e.g., FileNotFoundException before IOException before Exception).

28. Apart from try-catch, how can you handle exceptions in Java?

Answer: Using the throws keyword to delegate handling to the caller.

29. Difference between Thread.sleep() and Thread.wait().

Answer: sleep() is timed and doesn’t release locks; wait() is for synchronization and releases the lock until notified.
