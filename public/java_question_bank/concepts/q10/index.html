Beginner (Basics)

1. What is the use of pom.xml in your project?

Answer: It is the Project Object Model file for Maven. It manages the project’s dependencies, plugins, and build configurations.

2. What are the dependencies used in your project?

Answer: Common dependencies include selenium-java, cucumber-java, junit or testng, and apache-poi for Excel reading.

Intermediate (Configuration & Usage)

3. Other than dependencies, what else is present in the pom.xml file?

Answer: It contains plugins (like maven-surefire-plugin), properties (like Java version), and project metadata (name, version, groupID).

4. What is the purpose of the Maven Pretty and Plugin configurations?

Answer: Plugins perform specific build tasks (compile, test). “Pretty” refers to formatting plugins that make output logs or reports more readable.

5. How do you handle test data and external data in your framework?

Answer: By using external files like Excel (via Apache POI), JSON, or Properties files to separate data from the test logic.

Advanced (Framework Architecture & Logic)

6. What do you know about Page Factory and how do you use it in a Java/Cucumber framework?

Answer: An extension of POM that uses @FindBy to locate elements. It is initialized in the constructor of Page classes using PageFactory.initElements(driver, this);.

7. Where do you store the expected output data in your framework for Assert validation?

Answer: In external data files (Excel/JSON) or in a dedicated Constants class to ensure centralized maintenance.
