Beginner (Basic Syntax & OOPS Basics)

1. What is an abstract class? Provide an example.

Answer: A class that cannot be instantiated and is used as a base for other classes. Example: abstract class Animal { abstract void eat(); }.

2. What is Abstraction and where is it used?

Answer: Hiding implementation and showing only functionality. Used in Java through interfaces and abstract classes.

3. Explain Polymorphism.

Answer: “Many forms.” Allows one interface to be used for a general class of actions (Overloading/Overriding).

4. What are Wrapper classes?

Answer: Classes that convert primitives into objects (e.g., Integer for int).

5. What is the purpose of the super keyword?

Answer: To refer to the immediate parent class instance or constructor.

6. What are the access modifiers and their differences?

Answer:

  • public: Access from anywhere.
  • protected: Same package + subclasses.
  • default: Same package only.
  • private: Same class only.

7. What is an exception in Java? How do you handle it?

Answer: An event that disrupts the program flow. Handled using try-catch blocks.

8. Difference between for loop and enhanced for loop.

Answer: for loop uses an index; enhanced for loop (for-each) iterates directly through elements.

9. What are the ways to convert a String to an Integer?

Answer: Using Integer.parseInt(str) or Integer.valueOf(str).

Intermediate (Practical Implementation & Differences)

10. Inheritance: How is it used in your project?

Answer: To share common methods (like browser setup) from a base class to specific test classes.

11. Where have you implemented Encapsulation in your Automation Framework?

Answer: In the Page Object Model (POM), by making locators private and exposing them through public methods.

12. Constructor types and explanations.

Answer: Default (no-arg) and Parameterized. Used to initialize objects.

13. What is final, finally, and finalize?

Answer: final is a keyword (constant); finally is a block (cleanup); finalize is a method (cleanup before GC).

14. Difference between static and instance variables.

Answer: static belongs to the class (one copy); instance belongs to the object (multiple copies).

15. Explain the difference between == and .equals().

Answer: == compares references; .equals() compares content.

16. What is the difference between StringBuffer and StringBuilder?

Answer: StringBuffer is thread-safe; StringBuilder is faster but not thread-safe.

17. Difference between Collection and Collections.

Answer: Collection is an interface; Collections is a utility class with static methods.

18. Explain the Collection framework briefly.

Answer: A unified architecture for storing and manipulating a group of objects using interfaces like List, Set, and Map.

19. Difference between Array and ArrayList.

Answer: Array is fixed size; ArrayList is dynamic.

20. Difference between List and Set.

Answer: List allows duplicates and maintains order; Set disallows duplicates.

21. Difference between Map and List.

Answer: List is a sequence of values; Map is key-value pairs.

22. Difference between Map and Set.

Answer: Set stores unique values; Map stores unique keys mapped to values.

23. Difference between throw and throws.

Answer: throw triggers an error; throws declares potential errors in method signature.

24. Difference between Exception, Error, and Assertion.

Answer: Exception is recoverable; Error is serious system failure; Assertion is for testing assumptions.

25. What is a NullPointerException?

Answer: Thrown when trying to access a member of a null object.

26. How do you iterate through a HashMap?

Answer: Using entrySet() with a for-each loop or iterator().

27. How many catch blocks can be used for a single try?

Answer: Multiple, but only one will execute (the first match).

Advanced (Internal Mechanics, Design & Framework Architecture)

28. What design patterns have you used in your Automation Framework?

Answer: Page Object Model (POM), Singleton, and Factory patterns.

29. What is the Singleton Design Pattern?

Answer: Restricts a class to one instance and provides global access.

30. Explain how we achieve 100% Abstraction in Java.

Answer: By using Interfaces (until Java 8 allowed default methods).

31. If you have 10 methods in an Interface and you implement all except one, what will happen?

Answer: The implementing class must be declared abstract, or it will cause a compilation error.

32. What is meant by Serialization and Deserialization in Java?

Answer: Converting an object to a byte stream (and back).

33. What is constructor chaining?

Answer: Calling one constructor from another within the same or parent class.

34. Difference between POM and Page Factory.

Answer: POM is a concept; Page Factory is a Selenium class that implements POM with lazy initialization using @FindBy.

35. Do we have many public classes inside a single Java file?

Answer: No, only one public class is allowed per file, matching the filename.

36. Can we execute Java code without the main() method?

Answer: Using a static block (pre-Java 7) or through testing frameworks like TestNG/JUnit.

37. Will the main method run without the static keyword?

Answer: No, the JVM will not recognize it as the entry point.

38. Can a finally block execute without try and catch blocks?

Answer: No, it must follow a try or try-catch block.

39. Explain Type Casting of objects in OOPS.

Answer: Upcasting (safe) and Downcasting (needs instanceof).

40. What is a functional interface?

Answer: An interface with exactly one abstract method (e.g., Runnable).

41. What is a lambda expression?

Answer: A short way to represent an anonymous function for functional interfaces.

42. Exception in superclass vs subclass.

Answer: If a superclass method throws an exception, the overriding subclass method can only throw the same or a subset of that exception.

43. Are you aware of HashMap and HashTable?

Answer: HashMap is faster and not thread-safe; HashTable is synchronized and legacy.

44. How many finally blocks can be used with a try block?

Answer: Only one.
