String Programs

  • Reverse a string.
  • Reverse each word in a string but keep the word position (Input: “Java is a programming language”, Output: “avaJ si a gnimmargorp egaugnal”).
  • Reverse a string in different ways:
    • Input: “Deepak Kumar”, Output: “Kumar Deepak” (Swap words)
    • Input: “Deepak Kumar”, Output: “ramuk kapeed” (Reverse entire string)
    • Input: “Deepak Kumar”, Output: “kapeed ramuk” (Reverse words but keep position)
  • Count the occurrence of each character in a string.
  • Count the frequency of a letter in a string.
  • Count the number of letters in a given string (e.g., “Hello” -> 5).
  • Count vowels and non-vowels in a string.
  • Remove all special characters from a string and print only alphanumeric characters.
  • Replace ‘.’ with a space in an email only between names (not after @).
  • Remove duplicates from a string without using Set or built-in methods (Input: “hello hi hi i am hello here”).
  • Input: String name = a2b3c2, Output: aabbbcc.
  • Count digits of ‘a’ in a sentence (Input: “My name is vaishnavi and I am working in Wipro”).
  • Separate numbers and alphabets from a mixed string.
  • Check if a string is a Palindrome.

  • Check if a number is an Armstrong number.

  • Find the minimum and maximum value in a collection of numbers.
  • Sort an ArrayList in ascending order.
  • Sort a 2D array: int[][]={{2,4,5},{3,4,7},{1,2,9}}.
