Java Programs

Java Programming Interview Questions - AiiTE Q Dump-Set_7.txt

String Programs

  • Reverse a string.
  • Reverse each word in a string (Input: “Good Girl”, Output: “dooG lriG”).
  • Remove duplicate words or characters from a string (Input: “Good hi hi”, Output: “good hi”).
  • Count the occurrence of each character in a string.
  • Find the occurrence of every character in “Welcome to Wipro”.
  • Find the number of alphabets in a sentence.
  • Separate numbers only from a string (Input: “09/24/2015”).
  • Check if a string is a Palindrome.
  • Print all possible combinations of a string (Input: “abc”, Output: “a, b, c, ab, bc, ac, abc”).

Array & Number Programs

  • Write a program for an ArrayList to add elements and remove the first one.
  • Write a program to loop through an ArrayList using four different methods (For loop, Advanced For loop, While loop, Iterator).
  • Find the second largest number in an array.
  • Print descending order of an array.
  • Print non-repeating numbers in an array.
  • Sort an array in ascending order.
  • Write a Factorial program.
  • Swap two variables without using a 3rd variable.
  • Star pattern program (e.g., Pyramid).

Logic/Exception Handling

  • Write a program that generates an ArithmeticException (Divide by zero) and handles it.
  • Demonstrate the use of the throws keyword in a program.
  • Demonstrate the use of the finally keyword in a program.
