Beginner (Basics)

Reverse string using loop

String s = "Java", rev = "";
for(int i = s.length()-1; i>=0; i--) rev += s.charAt(i);

Find Min and Max in array

int[] arr = {5, 2, 8, 1};
int min = arr[0], max = arr[0];
for(int x : arr) {
    if(x < min) min = x;
    if(x > max) max = x;
}

Intermediate (Intermediate Logic)

Input: abc, Output: aabbcc

String s = "abc";
String res = "";
for(char c : s.toCharArray()) res = res + c + c;
// Output: aabbcc

Advanced (Advanced Algorithms & Logic)

Find duplicate and unique characters

String s = "weqjhjkAJKDbdnmbcnm";
Map<Character, Integer> counts = new LinkedHashMap<>();
for(char c : s.toCharArray()) counts.put(c, counts.getOrDefault(c, 0) + 1);

System.out.println("Duplicates:");
counts.forEach((k,v) -> { if(v > 1) System.out.print(k); });
System.out.println("\nUniques:");
counts.forEach((k,v) -> { if(v == 1) System.out.print(k); });
