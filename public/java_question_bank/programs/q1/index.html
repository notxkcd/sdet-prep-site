Java Programming Study Guide - 2025 Interview Questions

Beginner (Basic Logic & Loops)

1. Swap two numbers using a temporary variable.

Solution:

int a = 10, b = 20, temp;
temp = a; a = b; b = temp;

2. Write a code for String reverse.

Solution:

String s = "Java", rev = new StringBuilder(s).reverse().toString();

3. Reverse a number in Java.

Solution:

int n = 123, rev = 0;
while(n != 0) { rev = rev * 10 + n % 10; n /= 10; }

4. Print “Infosys” but skip the letter “o”.

Solution:

String s = "Infosys";
System.out.println(s.replace("o", ""));

5. How to replace a letter from a string?

Solution:

String s = "apple";
s = s.replace('a', 'b');

6. Replace vowels with * (Input: “chennai”).

Solution:

String s = "chennai";
s = s.replaceAll("[aeiouAEIOU]", "*");

7. Find the maximum and minimum values in an array.

Solution:

int[] arr = {1, 5, 3};
int max = Arrays.stream(arr).max().getAsInt();
int min = Arrays.stream(arr).min().getAsInt();

8. Find the smallest value in an array.

Solution:

int min = arr[0];
for(int x : arr) if(x < min) min = x;

9. Print all dividends of 8 between 1 and 100.

Solution:

for(int i=1; i<=100; i++) if(i % 8 == 0) System.out.println(i);

10. Sum the integers found in a mixed string.

Solution:

String s = "1a2b3";
int sum = 0;
for(char c : s.toCharArray()) if(Character.isDigit(c)) sum += Character.getNumericValue(c);

11. Write a code for Palindrome.

Solution:

boolean isPal = s.equals(new StringBuilder(s).reverse().toString());

Intermediate (Intermediate Strings, Arrays & Logical Reasoning)

12. Swap two variables without using a 3rd variable.

Solution:

a = a + b; b = a - b; a = a - b;

13. Fibonacci series code.

Solution:

int a=0, b=1;
for(int i=0; i<10; i++) { System.out.print(a + " "); int n=a+b; a=b; b=n; }

14. Write a sorting program.

Solution:

Arrays.sort(arr);

15. Find the second maximum value in an array.

Solution:

Arrays.sort(arr);
int secondMax = arr[arr.length - 2];

16. Find duplicate numbers in an array.

Solution:

Set<Integer> set = new HashSet<>();
for(int x : arr) if(!set.add(x)) System.out.println(x);

17. Count the occurrence of a character in a string.

Solution:

long count = s.chars().filter(ch -> ch == 'a').count();

18. Separate String and Integer from a mixed list or array.

Solution:

List<Integer> ints = new ArrayList<>();
List<String> strs = new ArrayList<>();
for(Object o : list) {
    if(o instanceof Integer) ints.add((Integer)o);
    else strs.add(o.toString());
}

String[] w = "test program".split(" ");
String res = w[1] + " " + w[0];

21. Extract ABC and 123 from “AB12C3” and print “ABC123”.

Solution:

String s = "AB12C3";
String alph = s.replaceAll("[0-9]", "");
String nums = s.replaceAll("[^0-9]", "");
System.out.println(alph + nums);

22. Input: Same, Output: Saammmeeee.

Solution:

String s = "Same", res = "";
for(int i=0; i<s.length(); i++) {
    for(int j=0; j<=i; j++) res += s.charAt(i);
}

Advanced (Advanced Algorithms, Complex Manipulations & Optimization)

23. Check if two strings are Anagram.

Solution:

char[] c1 = s1.toCharArray(); char[] c2 = s2.toCharArray();
Arrays.sort(c1); Arrays.sort(c2);
boolean isAnagram = Arrays.equals(c1, c2);

24. Reverse each word without changing caps/small position.

Solution:

String[] words = s.split(" ");
String res = "";
for(String w : words) res += new StringBuilder(w).reverse() + " ";

25. Remove duplicates from a string and print unique values.

Solution:

String res = Arrays.stream(s.split("")).distinct().collect(Collectors.joining());

26. Count words greater than 5 and reverse only those.

Solution:

String[] words = s.split(" ");
for(int i=0; i<words.length; i++) if(words[i].length() > 5) words[i] = new StringBuilder(words[i]).reverse().toString();

27. Split letters and numbers from a string and print separately.

Solution:

System.out.println(s.replaceAll("[^0-9]", ""));
