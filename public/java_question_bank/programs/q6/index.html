Beginner (Basics)

1. Reverse a string.

Solution:

String s = "Java";
String rev = new StringBuilder(s).reverse().toString();

2. Reverse an integer number.

Solution:

int n = 1234, rev = 0;
while(n != 0) {
    rev = rev * 10 + n % 10;
    n /= 10;
}

3. Count vowels in a string (e.g., “welcome”).

Solution:

String s = "welcome";
long count = s.toLowerCase().chars().filter(ch -> "aeiou".indexOf(ch) != -1).count();

4. Print vowels from a string.

Solution:

String s = "welcome";
for(char c : s.toCharArray()) if("aeiou".indexOf(c) != -1) System.out.println(c);

5. Find the maximum and minimum numbers in an array.

Solution:

int[] arr = {10, 20, 5};
int max = Arrays.stream(arr).max().getAsInt();
int min = Arrays.stream(arr).min().getAsInt();

6. Swap two numbers without using a third variable.

Solution:

a = a + b; b = a - b; a = a - b;

7. Find the count of letters in a string.

Solution:

int count = s.replaceAll("[^a-zA-Z]", "").length();

8. Replace ‘-’ with ‘/’ in a date string (Input: “03-06-1995”).

Solution:

String date = "03-06-1995";
String newDate = date.replace('-', '/');

9. How to get system date and time?

Solution:

System.out.println(java.time.LocalDateTime.now());

10. Convert a string to an integer.

Solution:

int n = Integer.parseInt("123456");

11. Get all variables from an array using a loop.

Solution:

for(int x : arr) System.out.println(x);

Intermediate (Intermediate Logic)

12. Reverse a string word by word.

Solution:

String[] words = s.split(" ");
String res = "";
for(int i = words.length-1; i >= 0; i--) res += words[i] + " ";

13. Count duplicate characters in a string.

Solution:

Map<Character, Integer> map = new HashMap<>();
for(char c : s.toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);
map.forEach((k,v) -> { if(v > 1) System.out.println(k + ":" + v); });

14. Find the frequency of characters in a string.

Solution:

Map<Character, Integer> map = new HashMap<>();
for(char c : s.toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);

15. Find duplicate words in a string (e.g., “Hexaware”).

Solution:

String[] words = s.split(" ");
Set<String> set = new HashSet<>();
for(String w : words) if(!set.add(w)) System.out.println(w);

16. Reverse two numbers without using a temporary variable.

Solution:

x = x + y; y = x - y; x = x - y;

17. Reverse two strings without using a temporary variable.

Solution:

a = a + b; b = a.substring(0, a.length() - b.length()); a = a.substring(b.length());

18. Find the second highest number in an array.

Solution:

Arrays.sort(arr);
int secondMax = arr[arr.length - 2];

19. Find duplicate elements in an array.

Solution:

Set<Integer> set = new HashSet<>();
for(int x : arr) if(!set.add(x)) System.out.println(x);

20. Sort an array.

Solution:

Arrays.sort(arr);

21. Convert an array to a list.

Solution:

List<Integer> list = Arrays.asList(arr);

22. Retrieve key-value pairs from a HashMap (Input: X = "A", Y = "B").

Solution:

for(Map.Entry<String, String> entry : map.entrySet()) System.out.println(entry.getKey() + ":" + entry.getValue());

23. Write a POJO class for Username and Password.

Solution:

class User {
    private String u; private String p;
    public String getU() { return u; } public void setU(String u) { this.u = u; }
    public String getP() { return p; } public void setP(String p) { this.p = p; }
}

Advanced (Advanced Algorithms & Logic)

24. Reverse a string word by word but keep word position.

Solution:

String res = Arrays.stream(s.split(" ")).map(w -> new StringBuilder(w).reverse().toString()).collect(Collectors.joining(" "));

25. Find repeated characters in the word “ASSASINATION”.

Solution:

Map<Character, Integer> map = new HashMap<>();
for(char c : "ASSASINATION".toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);

26. Remove duplicates from a string without using collection concepts.

Solution:

String res = ""; for(int i=0; i<s.length(); i++) if(!res.contains(""+s.charAt(i))) res += s.charAt(i);

27. Anagram check: Determine if two string patterns are the same.

Solution:

char[] c1 = s1.toCharArray(); char[] c2 = s2.toCharArray();
Arrays.sort(c1); Arrays.sort(c2);
boolean res = Arrays.equals(c1, c2);

28. Count characters, numbers, and special characters in a mixed string.

Solution:

int l=0, d=0, s=0;
for(char c : str.toCharArray()) {
    if(Character.isLetter(c)) l++; else if(Character.isDigit(c)) d++; else s++;
}

29. Find the 3rd maximum element in an array.

Solution:

Arrays.sort(arr); int thirdMax = arr[arr.length - 3];

30. Sum of two integer arrays.

Solution:

int[] sum = new int[arr1.length];
for(int i=0; i<arr1.length; i++) sum[i] = arr1[i] + arr2[i];

31. Find common duplicates between two arrays.

Solution:

Set<Integer> s1 = new HashSet<>(Arrays.asList(a));
for(int x : b) if(s1.contains(x)) System.out.println(x);
