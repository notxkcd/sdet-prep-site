Questions with Answers

Beginner (Basic Definitions & Keywords)

1. What is oops?

Answer: Object-Oriented Programming (OOPS) is a paradigm that uses “objects” to design software, focusing on data and its interactions.

2. What is inheritance?

Answer: A mechanism where one class (child) acquires the properties and behaviors of another class (parent).

3. Brief about encapsulation?

Answer: Bundling data and methods into a single unit (class) and hiding internal details using private.

4. What is abstraction?

Answer: Hiding complex implementation details and showing only the essential features to the user.

5. Explain the this keyword?

Answer: Refers to the current instance of the class.

6. What is the super keyword in Java?

Answer: Refers to the immediate parent class object.

7. Explain static keyword?

Answer: Means the variable or method belongs to the class itself, not to any specific instance.

8. What is the purpose of the static keyword in Java?

Answer: For memory management; it creates a single copy of the member shared by all objects.

9. Static keyword usage and purpose?

Answer: Used for common properties (like company name) or utility methods that don’t need object state.

10. Constant variables in Java?

Answer: Variables whose value cannot change, declared using final.

11. What are getters and setters in Java?

Answer: Public methods to retrieve (get) and update (set) private fields.

12. Explain Primitive and non-Primitive data types?

Answer: Primitives (int, char) store values directly; Non-Primitives (String, Array) are objects and store references.

13. What are collections?

Answer: A framework that provides a set of classes and interfaces to store and manipulate a group of objects.

14. What is break and continue in Java?

Answer: break exits a loop; continue skips the current iteration and goes to the next.

15. What is a Java abstract class?

Answer: A class that cannot be instantiated and can have both abstract and concrete methods.

Intermediate (Differences & Practical Usage)

1. Difference between an abstract class and an interface?

Answer: Abstract Class can have state and implemented methods; Interface is a contract (mostly abstract methods).

2. What’s the difference between a class and an interface?

Answer: A class is a blueprint for objects; an interface is a blueprint for class behavior.

3. Difference between == and .equals()?

Answer: == compares memory addresses; .equals() compares the actual content/value.

4. Difference between final, finally, and finalize?

Answer: final is a keyword (constant); finally is a block (cleanup); finalize is a method (garbage collection).

5. Difference between throw and throws?

Answer: throw is used to trigger an error; throws declares potential errors in method signatures.

6. Method overloading?

Answer: Multiple methods with the same name but different parameters in the same class.

7. What is method overriding? How to achieve it in your project?

Answer: Redefining a parent’s method in a child class with the same signature. Used to customize behavior.

8. Constructor: Default constructor execution and usage in your project?

Answer: A special method to initialize objects. Default constructor is provided by Java if none is written.

9. Why is String immutable in Java?

Answer: For security, caching (String Pool), and thread-safety.

10. What is the difference between StringBuffer and StringBuilder?

Answer: StringBuffer is synchronized (thread-safe); StringBuilder is not (faster).

11. Difference between List and Set?

Answer: List allows duplicates and keeps order; Set disallows duplicates and is unordered.

12. What is the difference between List and ArrayList?

Answer: List is an interface; ArrayList is a specific implementation of that interface.

13. What are the types of String?

Answer: String Literal (in pool) and String Object (using new on heap).

14. Explain wrapper classes?

Answer: Classes that wrap primitives into objects (e.g., int to Integer).

15. Methods used to compare strings and their differences?

Answer: equals() (content), equalsIgnoreCase() (ignores case), and compareTo() (lexicographical).

16. Name a few methods you use for String and Collections?

Answer: String: substring(), split(). Collections: add(), size(), remove().

17. Difference between ("") or (" ") when using methods like split?

Answer: ("") splits by every character; (" ") splits by single spaces.

Advanced (Internal Workings, Exceptions & Design)

1. Explain checked and unchecked Exceptions?

Answer: Checked are caught at compile-time (e.g., IOException); Unchecked happen at runtime (e.g., NullPointerException).

2. Can we create an object for an abstract class? If no, how can we access methods from an abstract class?

Answer: No. Access them through a child class that extends the abstract class.

3. Why can’t a constructor be overridden?

Answer: Because a constructor name must match the class name, and constructors are not inherited.

4. Is it possible to have two main classes? Why?

Answer: Yes, each class can have its own main method, but you must specify which one to run.

5. Difference between a static block and the Main class (public static void main). Which one will run first?

Answer: The static block runs first when the class is loaded, before main.

6. How do we use a variable and class which is the same in another class in Java?

Answer: Using fully qualified names (package + class name) or by importing.

7. Explain the wait concept in Java (Wait/Notify)?

Answer: Used for inter-thread communication to make a thread wait for a resource and notify others when released.

8. What is the Singleton design pattern?

Answer: Ensures a class has only one instance and provides a global access point to it.

9. Explain Collections and its types?

Answer: A framework for objects. Types include List, Set, Map, and Queue.
