Beginner (Basics)

Difference between JDK and JRE?

  • JRE: Just runs the programs (Java Runtime Environment).
  • JDK: Used to develop and run programs (Java Development Kit). It includes JRE + compiler (javac).

How to read input in Java?

Using the Scanner class:

Scanner sc = new Scanner(System.in);
String name = sc.nextLine();

Intermediate (Differences & Practical Logic)

Method Overloading vs Overriding?

  • Overloading: Same class, different parameters.
  • Overriding: Different classes (parent/child), same parameters.

List vs Set?

  • List: Keeps order, allows duplicates.
  • Set: No duplicates, no guaranteed order.

Advanced (Internal Mechanics & Complex Scenarios)

Static vs Dynamic Binding?

  • Static (Early): Resolved at compile-time (e.g., static or private methods).
  • Dynamic (Late): Resolved at run-time (e.g., overridden methods).

What is Synchronization?

It is a process that allows only one thread to access a resource at a time to prevent data inconsistency. Use the synchronized keyword.
