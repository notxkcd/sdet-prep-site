Beginner (Fundamentals)

What is abstraction?

Abstraction is hiding the complex “how” and showing only the essential “what.” For example, you know how to use a TV remote (what), but you don’t need to know the internal circuitry (how).

What is the static keyword?

It means the variable or method belongs to the class, not to any specific object. It stays in memory as long as the class is loaded.

What is a HashMap?

A collection that stores data in Key-Value pairs. You use a unique key to quickly find a specific value.

What is a NullPointerException?

An error that happens when you try to use an object reference that hasn’t been initialized (it points to null). Avoid it by using null checks.

Intermediate (Implementation & Logical Differences)

Difference between final and finally?

  • final: Used to restrict (constant variable, can’t override method, can’t inherit class).
  • finally: A block of code that always runs after a try-catch block, usually for cleanup.

Difference between throw and throws?

  • throw: Used inside a method to actually throw an exception.
  • throws: Used in the method signature to declare that this method might throw an exception.

Difference between List and Set?

  • List: Ordered collection that allows duplicates.
  • Set: Unordered collection that disallows duplicates.

Advanced (Deep Dives & Scenarios)

How are OOPS concepts applied in Selenium?

  • Encapsulation: Locators are private in Page Classes.
  • Inheritance: Test classes extend a BaseTest.
  • Polymorphism: WebDriver driver = new ChromeDriver();
  • Abstraction: Using WebElement methods without knowing the HTML parsing logic.

What is a functional interface?

An interface that has exactly one abstract method. Examples: Runnable, Callable. They are used primarily with Lambda expressions.

Difference between Thread.sleep() and Thread.wait()?

  • sleep(): From Thread class. The thread stops for a fixed time. It does not release the lock.
  • wait(): From Object class. Used in synchronization. The thread waits until notify() is called. It releases the lock.
