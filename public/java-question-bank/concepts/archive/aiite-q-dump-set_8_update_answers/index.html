Beginner (Basics)

Explain the OOPS concepts:

  • Encapsulation: Wrap data and code together.
  • Inheritance: Acquire properties from parent.
  • Polymorphism: Perform one task in different ways.
  • Abstraction: Hide internal complexity.

What is a constant variable in Java?

A variable whose value cannot be changed once assigned. It is declared using the final keyword. final int MAX_VALUE = 100;

Intermediate (Detailed Comparisons)

Differences between a class and an interface?

  • Class: Can have instance variables and fully implemented methods.
  • Interface: Can only have constants and (mostly) abstract methods. A class implements an interface but extends another class.

What methods are available under List and Set?

  • List: add(), get(), remove(), set(), indexOf(), size().
  • Set: add(), remove(), contains(), isEmpty(), size(), clear(). (Note: Set does not have get(index) because it is unordered.)
