What is TestNG?

TestNG is a Testing Framework for Java. It is more advanced than JUnit and provides features like grouping, prioritizing, and parameterization.

List TestNG annotations execution order:

  1. @BeforeSuite
  2. @BeforeTest
  3. @BeforeClass
  4. @BeforeMethod
  5. @Test
  6. @AfterMethod
  7. @AfterClass
  8. @AfterTest
  9. @AfterSuite

What is a Data Provider?

A TestNG feature that allows you to run a single test method multiple times with different sets of data.

How to rerun failed test cases?

  • Manual: Run the testng-failed.xml file generated in the test-output folder.
  • Automatic: Implement the IRetryAnalyzer interface.

How to set priority?

Use the priority attribute in the @Test annotation. @Test(priority = 1) (Note: If no priority is set, tests run alphabetically. Negative priorities run first.)

How to perform parallel execution?

In the testng.xml file, set the parallel attribute (e.g., parallel="methods") and specify the thread-count.
