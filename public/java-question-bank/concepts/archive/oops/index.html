OOPS Concepts (General & Java)

  • What is OOPS? Explain its key principles (Modularity, Reusability, Scalability, Real-World Modeling, Security).
  • Explain the “four pillars” of OOPS: Encapsulation, Inheritance, Polymorphism, and Abstraction.
  • What is the difference between a Class and an Object?
  • Explain the difference between Association, Aggregation, and Composition.
  • How is OOPS implemented in Java specifically?
  • What are the types of Inheritance supported in Java?
  • Explain the difference between Compile-time (Overloading) and Run-time (Overriding) Polymorphism.
  • What is Type Casting? Explain Upcasting and Downcasting with examples.
  • What is the difference between an Abstract Class and an Interface?
  • Explain how OOPS concepts are applied in a Selenium automation framework (e.g., POM, WebDriver interface).

Strings

  • What is the difference between a String Literal and a Non-Literal String (using new)?
  • How does the String Pool work in Java?
  • Explain why Strings are immutable and how it relates to encapsulation.

Arrays

  • What is the syntax for declaring, initializing, and accessing arrays in Java?
  • How can arrays be used to demonstrate polymorphism?
