Java Concepts

Java Concept Answers - 2025 Interview questions.md

Beginner (Basics)

What is static keyword?

static means the member belongs to the class itself, rather than a specific object. It is shared by all instances.

What are getters and setters?

Methods used to protect and access private variables. Getters retrieve values; Setters update them.

What are Primitive and non-Primitive data types?

  • Primitive: Basic types like int, char, boolean (stored directly).
  • Non-Primitive: Objects like String, Arrays, Classes (stored as references).

Intermediate (Practical Usage)

Difference between throw and throws?

  • throw: Used to explicitly throw an exception in a method.
  • throws: Used in a method signature to declare that a method might throw an exception.

Method Overloading vs Overriding?

  • Overloading: Same name, different parameters (Same class).
  • Overriding: Same name, same parameters (Parent vs Child).

What are Wrapper classes?

Classes that convert primitives into objects (e.g., int to Integer).

Advanced (Internal Workings)

Explain checked and unchecked Exceptions:

  • Checked: Checked at compile-time (e.g., IOException). You must handle them.
  • Unchecked: Checked at runtime (e.g., NullPointerException). Usually caused by bad logic.

What is the Singleton design pattern?

A design pattern that ensures a class has only one instance and provides a global point of access to it.

Explain the wait concept in Java (Wait/Notify):

Used for Inter-thread communication. wait() makes a thread pause until another thread calls notify() on the same object.
