Beginner

What are access modifiers?

Keywords that set the visibility of classes/methods:

  • public: Everywhere.
  • protected: Same package + subclasses.
  • default: Same package only.
  • private: Same class only.

What are Wrapper classes?

Classes like Integer and Double that allow us to treat primitives as objects.

Intermediate

Difference between static and instance variables?

  • Static: One copy per class. Shared by all objects.
  • Instance: One copy per object. Each object has its own.

Difference between throw and throws?

  • throw is an action (throwing the error).
  • throws is a warning (declaring the error in method signature).

Advanced

What is the Singleton Design Pattern?

Restricts a class to one instance.

public class Singleton {
    private static Singleton instance;
    private Singleton() {} // private constructor
    public static Singleton getInstance() {
        if (instance == null) instance = new Singleton();
        return instance;
    }
}

What is Serialization?

Saving an object’s state as a byte stream (implement Serializable interface).
