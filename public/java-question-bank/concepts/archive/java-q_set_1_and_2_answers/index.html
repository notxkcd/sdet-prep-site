Java Concepts

Java Concept Answers - Java Q_Set_1_and_2.md

Beginner (Fundamentals)

What is the use of the main method in Java?

It is the entry point of any Java program. The JVM looks for this method to start execution.

Difference between a class and an object?

  • Class: A template (blueprint).
  • Object: A physical instance (building) of that template.

What is the Scanner class?

A utility class used to read input from the user (keyboard).

Difference between .java and .class files?

  • .java: Source code written by the developer.
  • .class: Compiled bytecode that the JVM executes.

What is a Wrapper class?

A class that wraps a primitive (like int) into an object (like Integer). This allows primitives to be used in Collections.

What is the new keyword?

Used to create a new object and allocate memory on the heap.

Difference between while and do-while loops?

  • while: Checks condition first, then executes.
  • do-while: Executes once, then checks the condition.

Intermediate (Differences & Practical Logic)

Explain the OOPS concepts:

  • Inheritance: Reuse code from parent.
  • Polymorphism: One method, multiple behaviors.
  • Encapsulation: Data hiding.
  • Abstraction: Hiding implementation.

this vs. super keyword?

  • this: Refers to the current class instance.
  • super: Refers to the immediate parent class instance.

Difference between final, finally, and finalize?

  • final: Keyword to make a variable/method/class unchangeable.
  • finally: A block that always executes after try-catch.
  • finalize: A method called by Garbage Collector before destroying an object.

Why is String immutable?

For security, caching, and thread-safety. Values in the String Pool cannot be altered.

Difference between Array and ArrayList?

  • Array: Fixed size, holds primitives and objects.
  • ArrayList: Dynamic size, holds only objects.

Difference between List and Set?

  • List: Allows duplicates, maintains insertion order.
  • Set: No duplicates, does not guarantee order.

Advanced (Internal Mechanics & Complex Scenarios)

What is Polymorphism?

  • Static: Method Overloading (same class, different params).
  • Dynamic: Method Overriding (parent/child, same params).

What is a Copy Constructor?

A constructor that initializes a new object using the values of an existing object.

What is Constructor Chaining?

The process of calling one constructor from another (using this() or super()).

How does a HashMap work internally?

It uses Hashing. It stores data as Key-Value pairs in “buckets.” It uses hashCode() to find the bucket and equals() to find the specific key.

What is Serialization in Java?

The process of converting an object into a byte stream so it can be saved to a file or sent over a network.
