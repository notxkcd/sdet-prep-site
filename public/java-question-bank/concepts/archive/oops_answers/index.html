Beginner (Fundamentals)

What is OOPS?

Object-Oriented Programming (OOPS) is a way of designing software using “objects” that represent real-world things. These objects have data (attributes) and actions (methods).

What is the difference between a Class and an Object?

  • Class: A blueprint or template (e.g., a “Car” design).
  • Object: A real instance of that blueprint (e.g., your specific “Red Tesla”).

Explain the “four pillars” of OOPS:

  1. Encapsulation: Hiding data to keep it safe (using private).
  2. Inheritance: Sharing features from a parent to a child (using extends).
  3. Polymorphism: One thing having many forms (e.g., Overloading and Overriding).
  4. Abstraction: Showing only essential features and hiding the complex logic.

What is the syntax for declaring, initializing, and accessing arrays in Java?

  • Declare: int[] arr;
  • Initialize: arr = new int[5];
  • Access: arr[0] = 10;

What is the difference between an Abstract Class and an Interface?

  • Abstract Class: Can have both finished methods and unfinished (abstract) methods. Used for “is-a” relationships.
  • Interface: A contract that says “what to do,” not “how to do it.” Used for “can-do” behaviors.

Intermediate (Practical Concepts & Implementation)

Explain the key principles of OOPS:

  • Modularity: Breaking code into small, manageable pieces.
  • Reusability: Using existing code in new programs.
  • Security: Protecting data through encapsulation.

How is OOPS implemented in Java specifically?

Java uses classes to define objects, private fields for encapsulation, extends for inheritance, and interfaces for abstraction.

What are the types of Inheritance supported in Java?

  • Single: One parent, one child.
  • Multilevel: Grandparent -> Parent -> Child.
  • Hierarchical: One parent, many children. (Note: Java does NOT support Multiple Inheritance with classes to avoid confusion, but it does with Interfaces.)

Explain the difference between Compile-time (Overloading) and Run-time (Overriding) Polymorphism:

  • Overloading: Same method name, different parameters in the same class. (Resolved at compile time).
  • Overriding: Same method name and parameters in parent and child classes. (Resolved at run time).

What is the difference between a String Literal and a Non-Literal String?

  • Literal: String s = "Hello"; (Stored in the String Pool).
  • Non-Literal: String s = new String("Hello"); (Stored in the Heap).

Explain why Strings are immutable and how it relates to encapsulation:

Immutable means the value cannot be changed. This is for security and performance. It relates to encapsulation because it ensures that once a String is created, its internal state is protected.

Advanced (Internal Mechanics & Scenarios)

Explain the difference between Association, Aggregation, and Composition:

  • Association: A general relationship (e.g., Teacher and Student).
  • Aggregation: A “has-a” relationship where the parts can exist independently (e.g., Department and Teacher).
  • Composition: A strong “has-a” relationship where the parts cannot exist without the whole (e.g., Room and House).

What is Type Casting?

  • Upcasting: Casting a child to a parent (e.g., Animal a = new Dog();). Always safe.
  • Downcasting: Casting a parent to a child (e.g., Dog d = (Dog) a;). Needs instanceof check to be safe.

Explain how OOPS concepts are applied in a Selenium automation framework:

  • Encapsulation: Using Page Object Model (POM) to hide locators inside page classes.
  • Inheritance: Creating a BasePage that other pages extend.
  • Polymorphism: Using WebDriver driver = new ChromeDriver(); which can easily switch to FirefoxDriver.
  • Abstraction: Using the WebDriver interface to interact with browsers without knowing their internal logic.

How does the String Pool work in Java?

The String Pool is a special memory area. When you create a literal string, Java checks the pool; if it exists, it reuses the reference instead of creating a new object.

How can arrays be used to demonstrate polymorphism?

You can create an array of a parent type (e.g., Animal[]) and store different child objects (e.g., Dog, Cat) in it.
