Questions with Answers

Beginner (Basics)

1. Write a program to reverse a string?

Solution:

String s = "Java";
String rev = new StringBuilder(s).reverse().toString();

2. Write a program to find odd numbers in an array?

Solution:

int[] arr = {1, 2, 3, 4, 5};
for(int x : arr) if(x % 2 != 0) System.out.println(x);

3. Write a program demonstrating a Constructor and its uses?

Solution:

class Car {
    String model;
    // Constructor initializes the object state
    Car(String m) { this.model = m; }
}

Intermediate (Logical Reasoning)

1. Reverse a string word by word?

Solution:

String s = "my name is gomathy";
String[] w = s.split(" ");
String res = "";
for(int i=w.length-1; i>=0; i--) res += w[i] + " ";

2. Identify repeated characters in a string?

Solution:

String s = "programming";
Map<Character, Integer> map = new HashMap<>();
for(char c : s.toCharArray()) map.put(c, map.getOrDefault(c, 0) + 1);
map.forEach((k, v) -> { if(v > 1) System.out.print(k + " "); });

3. Find duplicate elements/characters in a string?

Solution:

Set<Character> seen = new HashSet<>();
for(char c : s.toCharArray()) if(!seen.add(c)) System.out.println("Duplicate: " + c);

4. Write a program demonstrating Method Overloading?

Solution:

class Calc {
    int add(int a, int b) { return a + b; }
    int add(int a, int b, int c) { return a + b + c; }
}

5. Write a Java pattern program (Generic)?

Solution:

for(int i=1; i<=5; i++) {
    for(int j=1; j<=i; j++) System.out.print("* ");
    System.out.println();
}

Advanced (Advanced Algorithms & Logic)

1. Change the first letter of every word in a sentence to uppercase?

Solution:

String s = "welcome to maveric systems";
String[] words = s.split(" ");
String res = "";
for(String w : words) res += w.substring(0,1).toUpperCase() + w.substring(1) + " ";

2. Combine two integer arrays into a third array, then extract only the odd numbers into a fourth array?

Solution:

int[] a = {1, 2}, b = {3, 4};
List<Integer> list = new ArrayList<>();
for(int x : a) list.add(x);
for(int x : b) list.add(x);
List<Integer> odds = list.stream().filter(n -> n % 2 != 0).collect(Collectors.toList());
