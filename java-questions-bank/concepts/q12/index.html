Questions with Answers

Beginner

1. Explain Maven and its purpose?

Answer: Maven is a build automation tool primarily used for Java projects. Its main purpose is to manage dependencies (external libraries) and provide a consistent build lifecycle.

2. Why are you using Maven in your project?

Answer: To automate the downloading of external JARs, ensure a uniform project structure, and easily manage the entire build process (compiling, testing, packaging).

Intermediate

1. What is the use of Maven and what are its goals?

Answer: Maven is used to simplify project management. Its “goals” are specific tasks (like clean, compile, or test) that belong to different phases of the project’s build cycle.

2. What does the pom.xml file in Maven do?

Answer: It is the Project Object Model file. It contains all project configurations, including dependencies, plugins, project version, and properties.

3. List common Maven goals?

Answer:

  • clean: Deletes the target folder.
  • compile: Compiles source code.
  • test: Runs the test cases.
  • package: Creates a JAR/WAR file.
  • install: Copies the package to the local repository.

4. What code do you use for Maven in your project?

Answer: This refers to the XML configurations in the pom.xml file, such as <dependency> tags for Selenium or TestNG, and <plugin> tags for report generation.
